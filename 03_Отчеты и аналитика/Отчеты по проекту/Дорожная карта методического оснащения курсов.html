2. Целевая модель методического комплекта курса

Единый стандарт «Методический комплект курса (ТЛ‑МК‑2026)», чтобы любой курс был одинаково проработан. Для каждого занятия и для курса в целом — набор документов:

Состав комплекта на курс

  • На уровне курса: карта курса / программа занятий, входная диагностика, памятка по технике безопасности, план оценки и аттестации, панель наставника (журнал прогресса и экспорт).
  • На уровне занятия: файл занятия (теория + практика), методичка занятия (что и как сделать, типичные ошибки), при необходимости рабочий лист (шаблон для заполнения, печать/PDF), инструкция (пошаговое «руками» для аппаратных операций).

3. Принципы и стандарты качества

  • Единый шаблон методички. Взять за эталон формат Blender/C#/мини-курсов: цель → пошаговые действия → «что должно получиться» → типичные ошибки → «проверь себя». Адаптировать под каждый курс.
  • Соответствие занятиям. Методички выпускаются строго под существующие файлы занятий (не придумывать новую структуру без согласования с чатом Б).
  • Стиль и токены. Единый визуальный язык (accent #1F6FE0, vr #4D008C, pr #167A4D) по образцу VR-курса.
  • Имена файлов. Русские, без «-» и «_» между словами (норма проекта).
  • Ссылки. Только открывающиеся в РФ без VPN; каждая проверяется перед публикацией.
  • Проверка. После каждой партии — машинный линк-чек (методичка → занятие → приложение → иллюстрации) и визуальная проверка рендера.
