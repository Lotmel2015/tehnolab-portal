## 1. Что показало исследование рынка (коротко)

- **Готового интерактивного тренажёра по труду/технологии с автопроверкой нет.** Для подготовки есть: официальные PDF-архивы (vserosolimp.edsoo.ru, olimpiada.ru, ЦПМ) и разрозненные самодельные тесты учителей. По физике/информатике такие инструменты есть (Сириус.Курсы, «Решу Олимп»), по труду — ниша свободна.
- **Форматы этапов:** теоретический тур — тесты + числовые ответы (можно автопроверять) + творческое задание на 5 баллов (нужна ручная проверка по чек-листу). Веса 0,5/1/1,5/2; частичного кредита нет.
- **Лучшие практики платформ** (что взяли в дизайн): мгновенная проверка + разбор «за что балл» (Решу, Сириус); статистика по разделам и для тренера (Яндекс Учебник, «Мои достижения»); интерливинг/перемешивание; серия из 20–25 заданий на время (формат тура); протоколы экспорта.

## 2. Доказательная база (методики, лежащие в основе)

| Принцип | Источник | Как реализовано в банке |
|---|---|---|
| **Эффект тестирования** (самопроверка > перечитывание) | Dunlosky et al. 2013; Roediger & Karpicke; метаанализ Frontiers 2021 (эффект 0.56) | «Сначала ответь — потом разбор»; ответы скрыты до нажатия; в туре — не видны до завершения |
| **Интервальные повторения** (SM-2/FSRS) | Cepeda et al. 2008; Anki-документация | Раздел «Ошибки» возвращает проваленные задания; интервалы 3/10/30 дней (обновляются при повторе) |
| **Интерливинг** (перемешивание тем) | Rohrer et al. 2019 (РКИ в классах); Kornell & Bjork 2008 | Флажок «интерливинг» перемешивает разделы; полный тур всегда из разных разделов |
| **Обратная связь** (важнее содержательный разбор, чем время) | Fyfe et al. 2021 (ManyClasses 1: эффект 0.002) | Каждый ответ сопровождается решением «почему так»; разбор веса «за что балл» |
| **Нагрузка** (оптимум ~1 ч/день, распределённо) | APA 2015; обзор K-12 2024; Ericsson (deliberate practice) | Рутина: 5 заданий/день (10–15 мин) или 20/нед для олимпийской группы; тур — не чаще 1 раза в 2 недели |
| **Геймификация умеренно** (streak — дисциплина; публичный лидерборд — риск демотивации) | Обзор лидербордов 2023; обзоры геймификации | Есть только «серия дней» (личный показатель), без публичного рейтинга |
| **Адаптивность** (подбор сложности) | Скопинг-обзор 2024 (59% — рост успеваемости) | Разделы и уровни сложности (база/средний/олимп.) в фильтре; интерфейс подстраивает набор под раздел |

## 3. Режимы работы тренажёра

1. **Тренировка по разделу** — фильтр по одному разделу + выбор интерливинга; мгновенная проверка, разбор каждого ответа, вес балла.
2. **Полный тур 120′** — 10 заданий из разных разделов, таймер 120 минут, ответы скрыты до конца, итоговый балл по ключу.
3. **Ошибки** — возвращает проваленные в прошлый раз задания (интервальное повторение).
4. **Экспорт протокола** — строка «+/- вес · раздел · вопрос · балл» для тренера (вносится в журнал группы).

## 4. Структура карточки задания

```
{ id, sec (раздел 1–11 по 80/20), lvl (1 база / 2 средний / 3 олимп.),
  w (0.5/1/1.5/2), type (mc|num), q, ans, tol, sol (разбор «за что балл») }
```

- `num` — числовой ответ с допуском `tol` (проверка по ключу, без частичного кредита);
- `mc` — выбор одного варианта;
- под `sol` — короткое объяснение + формула/правило, которое сверяется с ключом оригинала.

## 5. Текущее наполнение и план

- **Сейчас:** 17 заданий-типов (скелет) по 8 разделам — работает локально, без сервера, данные в localStorage.
- **Наполнение до 300–500:** задания берутся из официальных комплектов (задания + ключи) и раскладываются по разделам 80/20; приоритет — разделы 1–5 (ГЛУБИНА): ЕСКД/расчёты, машиноведение, материаловедение, электротехника, автоматика/IoT, затем 6–8 и «узнавание» (9–11).
- **Ручная проверка творческого задания** (5 баллов) — не входит в автопроверку; в банке такой тип помечается как «кейс» и проверяется тренером по чек-листу ЦПМК.

## 6. Метод рутины для школьника (норма, доказанная наукой)

- **Ежедневно:** 5 заданий (10–15 минут) — тариф «поддержание»;
- **3 раза в неделю** (олимпийская группа): 20 заданий порциями с интерливингом;
- **1 раз в 2 недели:** полный тур 120 минут;
- **перед турами:** раздел «Ошибки» — 30 минут повторение проваленного.
