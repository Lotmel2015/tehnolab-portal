2. Страницы и контент

  • Объединение (home): hero «5 лабораторий», лента LAB.01–07, карточки-курсы (7 шт, публичные), секция «Записаться» #join, CTA.
  • Программа: ДООП — пояснительная записка, нормативка, актуальность, структура (784 ч, «Проектный навигатор» сквозной).
  • Лаборатории (labs): раскрывающиеся модули LAB.01–07 — навыки, оборудование, профессии, соревнования, «твой итог» (2 направления в LAB.03).
  • Мотивация (motiv): взгляд ученика и родителя, список конкурсов (НТО, «Большие вызовы», Робофест/WRO, Сириус, Звезда, МОШ/Ломоносов/Физтех и др.) со ссылками на лабы и сайты.
  • Кадры (staff): матрица команды (10 ролей), статусы (занято/к найму/совмещение/партнёр), редактируемые ФИО, компетенции, должностные инструкции.
  • Финансирование (finance): 6 источников, гранты (9,5 млн ₽ и др.), смета, KPI заявки.
  • Контроль (control): 42 задачи, 8 контуров, дедлайны, автопросрочка, лента недели, «Требует внимания», журнал ТО, дашборд объединения, экспорт/импорт.

3. Личные кабинеты и роли

  • Вход/регистрация: через портал (единый tl.users), 3 роли — learner, teacher, admin; должности POSITIONS (10).
  • Кабинет (полноэкранный, вкладки):
    • ученик — Профиль (редактирование, смена пароля), Мои курсы (прогресс, код доступа, «Продолжить», перенос прогресса), Достижения (медали, сертификат), Уведомления;
    • педагог — + «Мои ученики» (сводка, деталка ученика, «Открыть все»);
    • админ — + «Пользователи» (поиск/фильтры), «Педагоги» (реестр и код учителя).
  • Интеграция с курсами: COURSE_CONFIG (8 курсов + C#), прогресс lesson_l/week_obj, блокировки, квизы TQuiz, мотивационная шкала (tl-scale.js, металлы Железо→Иридий, лидеры).

4. Сильные стороны

  1. Сквозная архитектура: один вход на портал → курсы, прогресс из всех форматов; единое ядро синхронизировано по 8 копиям.
  2. Управление для команды: контроль с ролями (админ/завуч/сотрудник), дашборд KPI, журнал ТО, экспорт-импорт — закрыты «болевые точки».
  3. Мотивация ученика: медали, сертификаты, квизы, шкала с лидерами — геймификация в курсах и ЛК.
  4. Адаптивность и тема: тёмная/светлая, адаптив под смартфоны.
  5. Насыщенный контент: полные карточки лабораторий, реальные конкурсы с льготами.

6. Рекомендации по улучшению

P1 — согласованность и доверие

  1. Единая цифра лабораторий — «5 лабораторий (7 направлений по LAB.01–07, ПД — сквозная)» во всех панелях.
  2. Единая доля практики — зафиксировать 67% (или 65%) в одном месте, синхронизировать дашборд и тексты.
  3. Форма записи — либо анкета (имя, контакт, лаборатория) в tl.waitlist из ядра, либо явная ссылка; сейчас данные не сохраняются.

P2 — полезность для пользователей

  1. Вывести мотивационную шкалу в портал/ЛК (рейтинг, металл-уровень).
  2. Глубокие ссылки на панели (#control, #staff и др.).
  3. Уведомление о записи + список заявок tl.waitlist у админа.

P3 — технический долг

  1. Скрывать admin-вкладки полностью для неавторизованных (или метка «только для команды»).
  2. Вынести константы («5 лабораторий/7 направлений/784 ч / доля практики») в единую точку конфигурации.
  3. Периодическая проверка внешних ссылок конкурсов.

7. Вывод

Портал функционально зрелый: полный цикл «портал → курс → ЛК → достижения → управление» реализован и согласован на уровне кода (валидность, теги, интеграция). Главные улучшения — не в добавлении функций, а в согласованности данных (лаборатории, %, запись) и UX-усилениях (шкала в ЛК, глубокие ссылки, видимость заявок).
Документ сформирован автоматически по результатам аудита портала (чтение, без правок кода). Отчёт аналитический — рекомендации P1/P2/P3 к исполнению не применялись.
