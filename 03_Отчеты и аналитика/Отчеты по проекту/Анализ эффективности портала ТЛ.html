3. Взгляд на портал с позиций штата ТЛ

👨‍💼 Заведующий (Руководитель ТЛ)

Что получает: полный доступ ко всем служебным разделам (Кадры, Финансы, Контроль), отчёт за неделю, экспорт данных, планёрку.

Болевые точки: раздел «Контроль» «сухой» — 137 слов, нет объяснений, что такое контуры; нет сводного дашборда «состояние ТЛ за неделю»; нельзя увидеть задачи всех сотрудников с одного экрана иерархически.

Рекомендация: добавить сводный «Дашборд руководителя»: готовность недели, просроченные задачи по всем ролям, динамика посещаемости.

👩‍🏫 Педагог ДО (Казакевич К.М.)

Что получает: 7 задач контроля (занятия по КТП, журнал, планирование, проектные команды, безопасность, методобъединение, проверка работ).

Болевые точки: нет личного входа для сотрудника — чтобы увидеть свои задачи, нужно войти как администратор; «Рефлексия» как термин в портале отсутствует, хотя в курсах она есть; для педагога нет быстрого перехода к журналу/КТП.

Рекомендация: ввести роль «сотрудник» с персональными вкладками (Мои задачи, Журнал, КТП) без входа администратором.

🧑‍🔧 Второй педагог ДО и студент-наставник

Что получает: задачи контроля (журнал, лаборатории, модули), но навигация та же — через админ-вход.

Рекомендация: для этих ролей достаточно «Моих задач» + доступа к материалам своих лабораторий; это снимет нагрузку с администратора.

🛠 Инженер-лаборант

Что получает: 7 задач: выдача комплектов, 3D-печать, журнал учёта, ТО, ПО, закупки, инвентаризация. Это самая насыщенная роль в контроле.

Болевые точки: в портале нет журнала учёта оборудования как приложения (задачи есть, а форма ведения — нет); «МТБ» не расшифрована.

Рекомендация: прикрутить простой «Журнал оборудования» (выдача/возврат/состояние) прямо в раздел Контроль.

📊 Методист

Что получает: задачи по статистике, соцсетям, конкурсному календарю, методсопровождению; есть файлы анкет и памяток.

Болевые точки: нет быстрых ссылок на анкеты/памятки из портала; нет агрегированной статистики (посещаемость, конкурсы) в едином виде.

Рекомендация: добавить методисту раздел «Банк материалов» со ссылками на анкеты, памятки, шаблоны отчётов.

🏭 Внешние эксперты (автоматизатор, конструктор, КИПиА, руководитель проекта)

Что получает: задачи контроля по своим модулям (мастер-классы, ЕСКД, аудит, сопровождение проектов).

Болевые точки: внешним специалистам неудобно входить в общий портал; нет «гостевой» витрины с их материалами.

Рекомендация: предусмотреть гостевой доступ (ссылка-приглашение) хотя бы к «Моим задачам» и приложенным методичкам модуля.

5. Рекомендации по оптимизации

Высокий приоритет (влияет на восприятие и работу)

P1 Единый счётчик лабораторий. ✓ Выполнено 14.10.2026: принята модель «5 лабораторий (6 программ направлений, моделирование = Blender 3D + КОМПАС-3D) + 1 сквозная программа «Проектный навигатор» (ПД)».
P1 Согласовать объём программы. ✓ Выполнено: 784 ч = 7 программ × 112 ч (5 лабораторий + ПД); теория 260 ч / практика 524 ч (66,8%). Внесено в kpi, «Общий объём», УТП портала.
P1 Личный кабинет сотрудника. Реализовать роль «сотрудник» (не админ): вкладки «Мои задачи», «Мой журнал», «КТП», «Материалы». Педагог/лаборант/методист видят только своё — без ручного входа админом.
P1 Ссылка на «Обратную связь». Дать сотрудникам быстрый доступ к анкете обратной связи из портала (в служебном блоке).

Средний приоритет

P2 Дашборд руководителя. Наверху «Контроля» добавить карточки: «Готовность недели», «Просрочено», «Выполнено», «Посещаемость», с переходами к деталям.
P2 Журнал оборудования для лаборанта. Простой инвентарь: выдача/возврат/состояние — в разделе «Контроль» для роли лаборанта.
P2 «Банк материалов» для методиста. Ссылки на анкеты, памятки, панель педагога, шаблоны отчётов — одним блоком.
P2 Inline-форма заявки. Кнопка «Записаться» + раскрывающаяся форма «оставьте Имя + телефон/email» (сохраняется в localStorage, уходит в спутник при публикации).
P2 Унификация «БАС». ✓ Выполнено: текстовые «БПЛА» заменены на «БАС» (основной термин); «БАС (БПЛА)» допустимо как вспомогательное пояснение. Осталась только ссылка на физическую папку Курс-БПЛА (переименование не требуется).

Низкий приоритет

P3 Добавить карту сайта/оглавление внизу главной.
P3 Заполнить meta description и добавить опен-граф-теги.
P3 Добавить aria-label/tabindex для интерактивных элементов (94 onclick → доступность).
P3 Подсказки-тултипы к терминам «контур», «МТБ», «КТП» в разделе Контроль.
P3 Добавить календарный учебный график в «Программу».
