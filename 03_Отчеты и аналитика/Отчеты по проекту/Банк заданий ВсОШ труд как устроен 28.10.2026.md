# Банк заданий ВсОШ по труду (технологии) — устройство, проверка, обратная связь

**Дата:** 28.10.2026
**Цель:** дать школьнику рабочий тренажёр с мгновенной проверкой и разбором, а тренеру — статистику по разделам.

---

## 1. Зачем и для кого

Банк решает три задачи: (1) регулярная практика в «весах» 0,5/1/1,5/2 без частичного кредита; (2) интервальное повторение ошибок; (3) прогноз результатов тура по разделам для тренера. Работает локально (файл HTML открывается в браузере) и в группе (тренер видит протоколы).

## 2. Источники и лицензия

- Задания и ключи берутся из открытых архивов: vserosolimp.edsoo.ru/tehnologiya, olimpiada.ru/activity/92/tasks, vos.olimpiada.ru (официальные комплекты ЦПМК и регионов 2021/22–2026/27).
- Все задания приводятся с указанием источника и года; в банк включаем только те, где ключ опубликован. Если ключа нет — задание помечаем «без ключа, для практики в группе» и не включаем в автопроверку.
- Название страницы/файла идентифицирует источник, чтобы любой ответ можно было сверить с оригиналом.

## 3. Структура банка (файл «Банк заданий ВсОШ труд.html»)

Формат записи (поля карточки):
- **id** — уникальный номер (например, `ESKD-017`);
- **раздел** (1–11 по стратегии 80/20) и **уровень** (Г/У/С);
- **вес** (0,5 / 1 / 1,5 / 2) и **корректный ответ/ключ**;
- **решение** — короткий разбор «почему так»;
- **источник/год** — ссылка на архив;
- **тип** — тест (выбор) / расчёт (открытый числовой) / сопоставление (drag или «впиши»);
- **статус в банке** — «ключ есть» / «без ключа».

### Режимы работы школьника
1. **Тренировка по разделу** — выбрать раздел и уровень, решать подряд, получить мгновенный фидбек: верно/неверно, вес, правильный ответ и «решение».
2. **Полный тур** — случайная выборка 20–25 заданий из всех разделов с весами и таймером 120 минут; финальный балл по ключу.
3. **Интервальное повторение** — карточка ошибок: задания, где было «неверно», возвращаются через 3/10/30 дней.

### Обратная связь (что видит школьник)
- **Мгновенно:** «верно (+1,5)» / «неверно (0) » + правильный ответ + решение.
- **После серии:** сводка по разделам (сколько из скольких, %), список самых частых ошибок.
- **Разбор «за балл»:** для открытых расчётов показываем «правильно по ключу, у вас X — не совпало», чтобы привыкнуть к формату без частичного кредита.

### Протоколы для тренера
- Кнопка «Экспорт протокола» — сохраняет JSON/текст: id заданий, дата, балл, время тура. Тренер ведёт динамику по каждому ученику (это замена «тетради ошибок» на уровне группы).
- Сортировка ошибок по разделам — видно, какой раздел «просел» у группы.

## 4. Проверка и качество
- Перед публикацией каждая карточка проходит самопроверку: ответ в банке сверяется с ключом оригинала (не с «похожим» решением).
- Числовые расчёты — строго по формуле из ключа; допуск на формат ввода (например, «98.3» и «98,3» нормализуются).
- Раз в сезон (перед школьным этапом) банк обновляется новыми комплектами прошедшего года.

## 5. Этапы создания
1. **Скелет**: структура карточек, 2–3 задания на каждый раздел как образец (готовится сейчас в «Банк заданий ВсОШ труд.html»).
2. **Наполнение I**: 100–150 заданий по ГЛУБИНА-разделам (1–6, 8) — приоритет для олимпийской группы.
3. **Наполнение II**: 50–80 «узнавательных» заданий (разделы 7, 9–11) — для тренажёра.
4. **Рутина группы**: 5 заданий в день (10–15 минут) для всех, 20 заданий в неделю для олимпийской группы; тренер раз в неделю смотрит протоколы.

## 6. Риски
- **Авторские/методические ошибки в ключах** — каждое включённое задание должно иметь официальный ключ; спорные — помечаются и решаются в группе на занятии.
- **Перегрузка школьника** — банк выдаёт нормированные порции, а не «решай весь файл».
- **Самообман** («посмотрел ответ до решения») — в режиме «Полный тур» ответы скрыты до конца серии.
