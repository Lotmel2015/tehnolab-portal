02·AТеория по шагам

1

Меню и комната

У игры есть сцены: меню (выбор комнаты) и игровая (где играют). Photon позволяет получать список открытых комнат и создавать новую.

Главное различие между сценами — в их назначении. Меню — это «прихожая»: здесь игрок вводит имя и выбирает, куда зайти. Игровая сцена — «комната встреч»: сюда попадают все подключённые игроки. Photon умеет искать уже открытые комнаты (метод GetCustomRoomList) и создавать новые (CreateRoom / JoinOrCreateRoom). Комнату можно ограничить числом игроков, закрыть паролем или сделать невидимой в списке — всё это параметры RoomOptions. Такое разделение и настройки есть в любой онлайн-игре: от «Соберись с друзьями» до «поиск матча по региону».

Пример
using Photon.Pun;
using Photon.Realtime;
public class RoomMaker : MonoBehaviourPunCallbacks {
    void Join(){
        // войти в комнату, если её нет — создать
        PhotonNetwork.JoinOrCreateRoom("ComNya",
            new RoomOptions{ MaxPlayers = 4, IsOpen = true }, null);
    }
}
Что ты увидишь
Игрок попадает в комнату «ComNya»; если её ещё нет — она создаётся автоматически.
Опция RoomOptionsЧто делает
MaxPlayersСколько игроков максимум в комнате (например 4)
IsOpentrue — комната открыта, false — закрыта для новых
IsVisibleвидна ли комната в общем списке (для «скрытых» игр)
Запомни. Room — комната. JoinOrCreateRoom входит или создаёт. RoomOptions — настройки: лимит игроков, открытость, видимость.
2

Как игрок появляется

Когда игрок вошёл в комнату, ему нужно создать своего персонажа в игровой сцене. Для этого при переходе в игровую сцену вызываем PhotonNetwork.Instantiate.

Тонкий момент: персонаж у каждого игрока «свой», но тот же самый для всех. PhotonNetwork.Instantiate создаёт экземпляр префаба у каждого в комнате, присваивая одинаковый ViewID. За счёт этого у всех на экранах появляется один общий персонаж, а не несколько копий. Этот вызов лучше делать при входе в игровую сцену (например, в OnJoinedRoom или Start у спавнера), и обязательно передавать имя префаба, лежащего в папке Resources. Так в реальных играх работают «точки появления» (spawn points): сервер решает, где должен родиться каждый игрок, и рассылает всем одинаковую команду.

Код
using UnityEngine;
using Photon.Pun;
public class Spawner : MonoBehaviourPunCallbacks {
    void Start(){
        if (PhotonNetwork.IsConnectedAndReady)
            PhotonNetwork.Instantiate("Player",
                Random.insideUnitSphere * 2f, Quaternion.identity);
    }
}
Что ты увидишь
У каждого игрока появился свой персонаж «Player»; у всех он один и тот же общий куб-аватар.
Запомни. Вход в комнату — у всех наступает событие; каждый создаёт своего персонажа через PhotonNetwork.Instantiate (префаб — в Resources).
3

Имя и роли

Храни имя игрока в PhotonNetwork.NickName — другие увидят его. Роль (например, охотник/убегающий) можно разыграть через случайно назначить при входе.

NickName — это маленькая «визитка», которая летит вместе с тобой в комнату: когда другой игрок смотрит твой объект или табло, он читает именно это имя. Роль же задаёт поведение: охотник догоняет, убегающий прячется. Способов распределения ролей несколько — можно назначить случайно при входе, выбрать по очереди или отдать право выбора первому (хосту). Имя и роль важно собрать ДО спавна персонажа, чтобы другие сразу знали, кто ты и как себя вести с тобой. Это основа любой командной игры: без имён и ролей игроки не поймут, кто друг, а кто соперник.

Пример
using Photon.Pun;
public class RoleAssign : MonoBehaviourPunCallbacks {
    public void SetRole(){
        PhotonNetwork.NickName = "Хантер"; // имя видно всем
        // роль: случайная каждому входу
        viewer.GetComponent<...>();
    }
}
Что ты увидишь
На табло появляется имя «Хантер», и у этого игрока — роль охотника.
Способ выдачи ролиПлюсыКогда удобно
Случайно при входеБыстро, никого не ждёмКороткие матчи, все равны
По очередиЧестное распределениеКомандные сессии
Решает хостУправление у «главного»Когда нужен «капитан»
Запомни. NickName — имя игрока для всех. Роль назначают до спавна, чтобы все знали, кто кем играет. Задай имя и роль до появления персонажа.
4

Список игроков

У комнаты есть свойство PlayerList — список всех, кто внутри. По нему можно выводить табло и определять, кто первый.

PlayerList — это массив объектов Player, у каждого из которых есть NickName и ActorNumber (порядковый номер игрока в комнате). ActorNumber помогает отслеживать «кто первый вошёл»: у первого будет наименьший номер. Чтобы табло обновлялось само, его значение перечитывают каждый кадр в Update() или при событии PlayerEnteredRoom. Так работают списки игроков в любой онлайн-игре: показывают имена, число игроков, «готов ли» каждый, а ещё используют для генерации логики — например, когда собралось минимум 2 игрока, игра начинает отсчёт.

Пример
using UnityEngine;
using UnityEngine.UI;
using Photon.Pun;
public class PlayerListUI : MonoBehaviour {
    public Text txt;
    void Update(){
        if (!PhotonNetwork.InRoom) return;
        string s = "В комнате: " + PhotonNetwork.CurrentRoom.PlayerCount + "\n";
        foreach (var p in PhotonNetwork.CurrentRoom.PlayerList)
            s += p.ActorNumber + ". " + p.NickName + "\n";
        txt.text = s;
    }
}
Что ты увидишь
На экране список вида «В комнате: 2» затем «1. Аня», «2. Боря» — с номерами игроков.
Свойство PlayerЧто хранит
NickNameИмя игрока, которое видно всем
ActorNumberПорядковый номер в комнате (кто первый вошёл)
IsMasterClientПравда ли этот игрок — хост комнаты
Запомни. PhotonNetwork.CurrentRoom.PlayerList — все игроки комнаты. ActorNumber показывает, кто первый. Обновляй табло в Update() или по событию PlayerEnteredRoom.
