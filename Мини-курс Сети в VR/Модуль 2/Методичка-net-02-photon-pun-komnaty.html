Photon PUN: комнаты и подключение игроков

Подробное руководство для школьника: как делать, зачем и что должно получиться.

Модуль 02НачинающимПодробно
Цель модуля. В этом модуле сделаем настоящую игру-«встречалку»: меню с кнопкой, вход в комнату и появление игроков. Научишься отличать меню от игровой сцены и создавать персонажа на сети.

0Что понадобится

  • Продолжаем проект из Модуля 1 — В нём уже есть PUN 2 и App ID.
  • Две сцены — Создадим Menu и Game (их можно сделать в одном проекте).
  • Персонаж-префаб — Обычный куб или готовая модель.

1Пошагово — делай по порядку

1Создай две сцены: Menu и Game

💡 В жизни игр разделяют: меню (где выбирают) и игру (где играют). Когда игрок нажимает «Играть», он переходит из меню в игру.

Что делать: File → New Scene дважды. Сохрани как Menu и Game. Добавь обе в File → Build Settings (перетащи их в список).

Что должно получиться
В Build Settings обе сцены видны в списке.
Осторожно: Если сцену не добавить в Build Settings, переход по кнопке не сработает.
2Сделай меню: поле имени и кнопка «Играть»

💡 Поле для имени, чтобы игроки знали, кто есть кто. Кнопка — чтобы войти в игру.

Что делать: В сцене Menu добавь: Canvas → Text (Подпись «Имя»), InputField (куда вводить имя), Button (текст «Играть»).

Что должно получиться
На экране меню есть поле, кнопка и заголовок.
3Напиши сценарий меню

💡 Скрипт сохраняет имя и запускает подключение.

Что делать: Создай скрипт MenuManager.cs и вставь код.

Код (копируй целиком)
using UnityEngine;
using UnityEngine.UI;
using UnityEngine.SceneManagement;
using Photon.Pun;

public class MenuManager : MonoBehaviour {
    public InputField nameInput;
    public void Play() {
        PhotonNetwork.NickName = nameInput.text == "" ? "Игрок" : nameInput.text;
        PhotonNetwork.ConnectUsingSettings();
    }
    void Update() {
        if (PhotonNetwork.IsConnectedAndReady)
            SceneManager.LoadScene("Game");
    }
}
Что должно получиться
После нажатия кнопки сцена переключается на Game.
4Создай персонажа в игровой сцене

💡 Когда игрок вошёл в комнату, ему нужно появиться в игре. Создаём персонажа через PhotonNetwork.Instantiate — так он появится у ВСЕХ.

СпособУ кого появитсяЗачем
InstantiateТолько у тебяЛокальные эффекты, личные детали
PhotonNetwork.InstantiateУ всех в комнатеОбщие персонажи и предметы

Что делать: Сделай префаб Player (куб со скриптом PlayerController и Photon View). В сцене Game добавь пустой объект Spawner со скриптом ниже.

Код (копируй целиком)
using UnityEngine;
using Photon.Pun;

public class Spawner : MonoBehaviourPunCallbacks {
    void Start() {
        if (PhotonNetwork.IsConnectedAndReady)
            PhotonNetwork.Instantiate("Player", Random.insideUnitSphere*2, Quaternion.identity);
    }
}
Что должно получиться
В игре появляется куб; если запустить дважды — два куба.
5Сделай простое управление (твой куб)

💡 Чтобы понять, что кубы «твои», добавь управление только своему кубу.

Что делать: В префаб Player добавь скрипт PlayerController.

Код (копируй целиком)
using UnityEngine;
using Photon.Pun;

public class PlayerController : MonoBehaviourPun {
    void Update() {
        if (!photonView.IsMine) return;  // управляем только своим кубом
        float h = Input.GetAxis("Horizontal");
        float v = Input.GetAxis("Vertical");
        transform.Translate(new Vector3(h, 0, v) * 3f * Time.deltaTime);
    }
}
Что должно получиться
Стрелки двигают твой куб, а чужой стоит.
6Выведи список игроков

💡 Табло игроков помогает видеть, кто в комнате — пригодится для командных игр.

Что делать: Добавь на Canvas текст PlayerListText и скрипт, который пишет список.

Код (копируй целиком)
using UnityEngine;
using UnityEngine.UI;
using Photon.Pun;

public class PlayerList : MonoBehaviour {
    public Text txt;
    void Update() {
        if (PhotonNetwork.InRoom) {
            string s = "";
            foreach (var p in PhotonNetwork.CurrentRoom.PlayerList) s += p.NickName + "\n";
            txt.text = s;
        }
    }
}
Что должно получиться
На экране список имён подключённых игроков.

2Типичные ошибки и как их исправить

Ошибка «Кнопка не переключает сцену». Жмёшь «Играть» — ничего.
Как исправить: Проверь: обе сцены в Build Settings, у кнопки назначен OnClick → MenuManager.Play, а nameInput привязан в Inspector.
Ошибка «Персонаж не появляется». После входа в Game нет куба.
Как исправить: Убедись, что префаб Player лежит в папке Resources и называется именно «Player», и у него есть Photon View.
Ошибка «Управляются все кубы сразу». Двигаешь свой — двигаются и чужие.
Как исправить: В PlayerController проверь photonView.IsMine (как в примере). Если забыть — управляются все.
Ошибка «Два одинаковых персонажа у одного игрока». После входа в Game появляются две копии.
Как исправить: Спавнер PhotonNetwork.Instantiate есть в сцене в единственном экземпляре. Если его добавить и на Player — появится лишний персонаж. Проверь, что скрипт-спавнер стоит только на одном объекте.
Ошибка «Не удаётся найти префаб Player». Ошибка в консоли при входе в Game.
Как исправить: Префаб «Player» обязан лежать в папке Resources (или подпапке) — Photon ищет сетевые префабы именно там, и имя должно точно совпадать со строкой в Instantiate.
Проверь себя (ответь устно или письменно):
  1. Зачем делить игру на сцены Menu и Game?
  2. Почему персонажа создаём через PhotonNetwork.Instantiate, а не Instantiate?
  3. Зачем нужен NickName?
  4. Где должен лежать сетевой префаб Player, чтобы Photon нашёл его?
  5. Как по коду понять, что объектом управляет только его владелец?
Итог модуля. Итог: есть меню, вход в комнату, появление персонажей у всех и список игроков. Готово к настоящей совместной игре!
