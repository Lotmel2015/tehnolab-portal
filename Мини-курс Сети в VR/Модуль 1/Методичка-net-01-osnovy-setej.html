Основы сетей в Unity

Подробное руководство для школьника: как делать, зачем и что должно получиться.

Модуль 01НачинающимПодробно
Цель модуля. В этом модуле ты поймёшь, как компьютеры и шлемы «общаются» между собой в одной игре. Мы подключим Unity к сервису Photon — это как «мост», по которому будут летать данные между игроками.

0Что понадобится

  • Unity любой версии — Подойдёт Unity 2021+; скачай с unity.com если ещё нет.
  • Аккаунт Photon (бесплатно) — Зарегистрируйся на dashboard.photonengine.com — это бесплатно, App ID получишь сразу.
  • Интернет — Нужен, чтобы сервер Photon соединил игроков.

1Пошагово — делай по порядку

1Установи PUN 2 (Photon Unity Networking)

💡 PUN 2 — это готовая библиотека, которая добавляет в Unity сетевую логику: подключение, комнаты, синхронизацию объектов. Без неё пришлось бы писать сеть с нуля — это очень сложно.

Что делать: Открой Unity → меню Window → Asset Store. Найди «Photon PUN 2 - Free» и нажми Import. Или через Package Manager добавь пакет PUN.

Что должно получиться
В окне Project появится папка Photon с настройками.
Осторожно: Если Asset Store не открывается, введи в Package Manager имя пакета PhotonPun2.
2Создай приложение в Photon и получи App ID

💡 Photon выделяет каждой игре свой «канал» — App ID. Чтобы твои игроки попали в ОДНУ и ту же «комнату», у всех должен быть один и тот же App ID.

Что делать: Открой dashboard.photonengine.com → Create A New Application → тип Realtime → скопируй App ID. В Unity: Window → Photon Unity Networking → PUN Wizard → подставь App ID → Setup.

Что должно получиться
В Photon Server Settings появится App ID, а рядом — ✓ признак готовности.
Осторожно: Скопируй ID целиком, без пробелов. Одна лишняя буква — и игроки не встретятся.
3Пойми главную схему: клиент, сервер, хост

💡 Чтобы двигаться дальше, нужно понимать роли. Клиент — устройство игрока. Сервер — «главный судья» мира. Хост — это сервер, на котором тоже играют. В PUN 2 каждый, кто создаёт комнату, становится хостом.

Что делать: Прочитай и запомни схему. Сверься с таблицей ролей.

РольКто этоЧто делает
КлиентУстройство игрокаШлёт серверу, что ты нажал, и рисует ответ
Сервер«Хозяин» мираХранит правду о мире, защищает от читеров
ХостСервер + игрокСоздал комнату и сам в ней играет (так в PUN 2)
Что должно получиться
Ты можешь объяснить, чем клиент отличается от хоста, и назвать, кто становится хостом в PUN 2 (тот, кто создал комнату).
4Сделай сетевой объект (Photon View)

💡 Обычный объект в сцене «видит» только один игрок. Чтобы объект был общим для всех, ему добавляют компонент Photon View — «табличка с номером» в сети.

Что делать: Создай в сцене Cube. Выдели его и в Inspector нажми Add Component → Photon View. Добавь также Photon Transform View (чтобы позиция передавалась другим).

Что должно получиться
У куба в Inspector появились Photon View и Photon Transform View.
Осторожно: Объект без Photon View НЕ будет виден другим игрокам — это самая частая ошибка новичков.
5Напиши скрипт для подключения

💡 Скрипт говорит Unity: «подключись к Photon и войди в комнату». Так два устройства встретятся в одном игровом мире.

Что делать: Создай скрипт Connection.cs, удали всё и вставь код ниже.

Код (копируй целиком)
using UnityEngine;
using Photon.Pun;
using Photon.Realtime;

public class Connection : MonoBehaviourPunCallbacks {
    void Start() {
        PhotonNetwork.ConnectUsingSettings();
    }
    override public void OnConnectedToMaster() {
        PhotonNetwork.JoinOrCreateRoom("room1", new RoomOptions{MaxPlayers=4}, null);
    }
    override public void OnJoinedRoom() {
        Debug.Log("Я в комнате! Игроков: " + PhotonNetwork.CurrentRoom.PlayerCount);
    }
}
Что должно получиться
При запуске (▶) в консоли появится «Я в комнате! Игроков: 1.»
6Проверь на двух устройствах

💡 Чтобы увидеть сеть в действии, запусти игру дважды: один раз в редакторе (Window → Play), второй — на собранном APK в шлеме. Оба попадут в комнату room1.

Что делать: Открой сразу два проигрывателя (режим Game параллельно) или собери APK и запусти на шлеме параллельно с редактором.

Что должно получиться
В обоих запусках в консоли «Игроков: 2.» — значит, они видят друг друга.

2Типичные ошибки и как их исправить

Ошибка ««Failed to connect (0)»». Не получается подключиться к Photon.
Как исправить: Проверь App ID в Photon Server Settings, интернет и что ты не в «офлайн-режиме» Unity.
Ошибка «Игроки не видят друг друга». Вошли в комнату, но кубов друг друга нет.
Как исправить: У объекта, который должен быть общим, обязательно добавлен Photon View + Photon Transform View, и он создаётся через PhotonNetwork.Instantiate (не Instantiate).
Ошибка «Каждый видит свой персонаж, но их двое у одного игрока». Спавнится два одинаковых куба.
Как исправить: PhotonNetwork.Instantiate вызывается в Start() у каждого игрока — это нормально (у каждого свой куб). Двойники появляются, если скрипт стоит сразу на нескольких объектах сцены. Оставь один объект-спавнер в сцене.
Ошибка «Не получается удержать объект в руках в VR». Предмет «выпадает» на землю у других.
Как исправить: Управлять физикой объекта может только владелец. Передавай владение через OwnershipTransfer, когда игрок берёт предмет в руки.
Проверь себя (ответь устно или письменно):
  1. Объясни своими словами: кто такой «хост»?
  2. Зачем объекту Photon View?
  3. Что такое App ID и зачем он нужен?
  4. Почему персонажа создаём через PhotonNetwork.Instantiate, а не Instantiate?
  5. Как узнать, твой ли это сетевой объект, внутри скрипта?
Итог модуля. Итог: ты установил PUN 2, подключил проект к Photon, создал сетевой объект и встретил двух игроков в одной комнате. Это фундамент любого multiplayer-VR.
