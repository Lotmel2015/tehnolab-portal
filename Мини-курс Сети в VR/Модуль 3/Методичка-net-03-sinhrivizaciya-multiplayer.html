Сети в VR · методичка

Синхронизация, сборка multiplayer-игры

Подробное руководство для школьника: как делать, зачем и что должно получиться.

Модуль 03НачинающимПодробно
Цель модуля. Заключительный модуль: сделаем честную совместную игру — когда движется один, это видят все, а счёт у всех одинаковый. Соберём финальный APK для двух шлемов.

0Что понадобится

  • Проект из Модуля 2 — Там уже есть меню, комнаты и персонажи.
  • Два устройства для финала — Editor+шлем или два шлема/ПК.
  • Терпение и внимание — Синхронизация любит аккуратность.

1Пошагово — делай по порядку

1Синхронизируй движение (Photon Transform View)

💡 По умолчанию, когда ты двигаешь куб, другие видят его застывшим. Photon Transform View «транслирует» позицию и поворот каждому.

РежимКак выглядит для другихКогда подходит
InterpolateОбъект плавно «доезжает» до новой точкиДвижение персонажей и рук — почти всегда
TeleportМгновенно прыгает на новое местоРедкие перемещения (портал, спавн)

Что делать: На персонажа (префаб Player) добавь компонент Photon Transform View и отметь галочками Position и Rotation (Synchronize Position и Rotation = Interpolate).

Что должно получиться
Когда один игрок ходит, другой видит его движение плавно.
Осторожно: Если не добавить — другие увидят «застывший» объект, который будет резко прыгать.
2Создай объект для сбора (монета)

💡 Сделаем предмет, который можно «взять» и всем пересчитать. Сначала просто куб-«монета».

Что делать: Создай префаб Coin (куб жёлтого цвета, Collider), положи в Resources. Сделай так, чтобы игрок мог собрать её (OnTriggerEnter).

Что должно получиться
Монета стоит в сцене на видном месте.
3Передай событие через RPC

💡 Обычный метод выполняется у одного игрока. RPC (Remote Procedure Call) — метод, который запускается у ВСЕХ одновременно. Идеально для «монета собрана!».

Что делать: В скрипт сбора добавь метод с атрибутом [PunRPC] и вызывай его через photonView.RPC.

Код (копируй целиком)
[PunRPC]
void PickupCoin() {
    Destroy(gameObject);
}

// вызываем у всех:
// photonView.RPC("PickupCoin", RpcTarget.AllBuffered);
Что должно получиться
Монета исчезает у всех игроков одновременно.
Осторожно: Забыл [PunRPC] — RPC не найдёт метод.
4Добавь сетевой счёт

💡 Чтобы было соревнование, у всех должен быть один и тот же счёт. Храни счёт на одном «главном» объекте и передавай изменения через RPC.

Что делать: Создай объект ScoreManager с Photon View. При сборе монеты увеличивай счёт и передавай новое значение через RPC.

Код (копируй целиком)
public class ScoreManager : MonoBehaviourPun {
    public int Score = 0;
    [PunRPC] void AddScore(int s) { Score += s; }
    void OnGUI() { GUILayout.Label("Счёт: " + Score); }
}
Что должно получиться
У обоих игроков показывается одинаковый растущий счёт.
Осторожно: Не храни счёт локально у каждого — будет расходиться.
5Собери логику «кто больше»

💡 Добавим условие победы, чтобы игра была законченной.

Что делать: Когда собрано, например, 5 монет, выведи сообщение и останови движение.

Код (копируй целиком)
[PunRPC] void Win(string name) {
    Debug.Log("Победил " + name + "!");
}
Что должно получиться
При достижении цели появляется сообщение о победителе.
6Собери APK и сыграй на двух шлемах

💡 Финал: настоящая multiplayer-игра на двух Pico 4 Ultra.

Что делать: Настрой Build Settings под Android, собери APK, установи на два шлема и запусти одновременно.

Что должно получиться
Два игрока играют вместе, видят друг друга и общий счёт.
Осторожно: Для теста нужны ДВА устройства одновременно.

2Типичные ошибки и как их исправить

Ошибка «Объект «дёргается»». Другой игрок видит прыгающий объект.
Как исправить: В Photon Transform View включи Interpolate и поставь меньший интервал отправки (в Photon Server Settings → Serialization).
Ошибка «RPC не срабатывает». Монета исчезает только у того, кто собрал.
Как исправить: Проверь [PunRPC] перед методом и что вызываешь photonView.RPC (а не просто метод).
Ошибка «Счёт у всех разный». У одного 3, у другого 1.
Как исправить: Дробление счёта происходит, если счёт хранится локально. Храни счёт в ScoreManager с Photon View и обновляй через RPC.
Ошибка «Монета исчезает, но другие её всё ещё видят». Событие не дошло до остальных.
Как исправить: Убедись, что у метода есть [PunRPC], и что вызов идёт через photonView.RPC("ИмяМетода", RpcTarget.AllBuffered ...), а не просто Pickup(). Также photonView должен быть на том же объекте, у которого вызывается метод.
Ошибка «После сборки APK игроки не встречаются». На двух шлемах никак не сходятся в комнату.
Как исправить: Проверь, что на обоих устройствах одинаковый App ID, что обе сцены добавлены в Build Settings и что не перепутан регион сервера Photon.
Проверь себя (ответь устно или письменно):
  1. Чем отличается обычная функция от RPC?
  2. Зачем Photon Transform View?
  3. Где хранить счёт, чтобы у всех был одинаковый?
  4. Почему не стоит слать каждый кадр по сети всё подряд?
  5. Что делает RpcTarget.AllBuffered?
