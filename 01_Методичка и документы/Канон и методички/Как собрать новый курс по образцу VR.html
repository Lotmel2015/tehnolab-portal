Как собрать новый курс по образцу VR-студии

Канонический чек-лист и шаблон для тиражирования: конфиг → хаб → уроки → шкала → проверки.

Версия 2.0 · 20.10.2026 · Источник образца: «Курс-VR-студия», «Курс C#», «Курс-Blender-3D», «Курс-Электроника», «Курс-БПЛА», «Курс-КОМПАС-3D», «Курс-Робототехника»

Главное. Каждый новый курс — это автономная папка с хабом («Список занятий / модулей») и набором уроков. Вся логика — на localStorage, без сервера и интернета. Чтобы курс заработал, достаточно заполнить один JSON-конфиг и прогнать генератор; чтобы он не сломался — соблюдать 4 жёстких правила: один префикс ключей, один <script>, никаких однострочных «//»-комментариев в минифицированном JS и строгая блокировка следующего шага через рефлексию.

4 жёстких правила (нарушение = сломанный курс)

1. Один префикс ключей на курс. Все ключи localStorage начинаются с префикса курса (vr_u_…, cs_u_…, bl_u_…). Никогда не используй чужие ключи и не расширяй ?reset=1 на чужие префиксы.
2. Один <script> на страницу. const из одного script-блока не виден в другом. Если скрипт большой — пиши его в одном <script>, весь код в нём.
3. Никаких «//»-комментариев в минифицированном JS. Однострочный комментарий «съедает» остаток строки и обрезает код (это уже ломало регистрацию). Используй только /* ... */.
4. Строгая блокировка следующего шага. Ссылка на следующее занятие открывается ТОЛЬКО если в localStorage записан reflKey === "1", а это происходит только через completeLesson() при заполненных всех 3 полях рефлексии + галочке «практика и ДЗ выполнены». Клик по ссылке без этого блокируется (preventDefault).

Чек-лист сборки (14 шагов)

  1. Создай папку курса по именованию «Курс-Название» и вложенные папки «Занятие 1» … скопируй образец Список занятий VR студии.html как основу хаба.
  2. Заполни JSON-конфиг (см. Шаг 0): prefix, title, teachers, total, lessons, scaleMetals, bonusLessons, resetScope.
  3. Пересобери хаб генератором: подставь конфиг в шаблон (один <script>!). Проверь, что рендерятся total карточек.
  4. Собери первый урок по скелету (секции из таблицы выше): копия и подмена текста, ссылка на хаб, reflKey = "{p}_u_" + uid + "_l_1".
  5. Подключи строгую блокировку: функции refreshState(), completeLesson(), click-guard на #nextLink — скопируй работающую реализацию из «Занятие 1» C#/Blender, не пиши заново.
  6. Добавь автосохранение черновика (_draft) и восстановление при загрузке — готовые функции pdPersistDraft + init-блок.
  7. Экспорт рефлексии: в личную папку (File System Access API) — скопируй reflSaveToFolder/buildReflection из VR; рефлексия подписывается ФИО ученика из профиля.
  8. Дублируй урок на все занятия: подмени l_1 → l_N, номер в заголовке, карту занятия, контент секций, ссылку «следующее».
  9. Добавь методичку к каждому уроку (формат «Что нажать / Что получится»).
  10. Собери мотивационную шкалу: в хаб вторым скриптом или тем же — __scaleRender, 10 металлов, таблица лидеров, звёзды качества.
  11. Проверь обратные ссылки: урок → хаб, «назад», хаб → урок №N; замени URL-кодировку пробелов/символов (например %D0%97...%20C%23.html).
  12. Настрой ?reset=1: чистить ТОЛЬКО ключи своего префикса. Никогда не добавляй чужие (cs_u_, pd_*, ...).
  13. Проверь последовательную блокировку: занятие N доступно только после N-1; у учителя открыто всё; заблокированная карточка — «locked» с пояснением.
  14. Прогони автотест (раздел «Проверки перед выдачей»): синтаксис, ссылки, регистрация, блокировка, шкала.

Проверки перед выдачей (обязательный минимум)

  • Синтаксис: каждый <script> проходит node --check / new vm.Script() без ошибок.
  • Ссылки: все href существуют (нет битых); ссылки на внешние ресурсы открываются без VPN.
  • Регистрация: новый ученик получает код; вход «Я уже есть» по коду работает; учитель входит по teacherCode; при повторной регистрации с тем же именем — предупреждение.
  • Роли: ученику видны только его занятия (заблокированные — «locked»), учителю — все; список учеников у учителя фильтруется по его имени.
  • Строгая блокировка: пустая рефлексия → отказ; 1-2 поля → отказ; все поля без галочки → отказ; только после всего — reflKey="1" и ссылка активна.
  • Click-guard: клик по «следующему» без прохождения не открывает ссылку (preventDefault + сообщение).
  • Рендер хаба: после входа появляется userBar, скрывается authPanel; число карточек = total; прогресс сохраняется после перезагрузки.
  • Шкала: __scaleRender рисует 10 уровней и таблицу лидеров; балл = 40% прогресс + 60% качество.
  • Один префикс: в localStorage курса нет ключей с чужим префиксом (cs_, pd_, bl_...).
  • Офлайн: страница полностью открывается из файла без интернета; печать из браузера даёт аккуратный вид.
Готово, когда: все галочки выше — «закрыты», автотест зелёный, и любой ученик с первого раза без подсказки регистрируется и доходит до занятия 2 только честно пройдя занятие 1.

Методический комплект курса · стандарт ТЛ-МК-2026

Полный методический комплект курса (после Этапов 1–3, 2026) состоит из двух уровней — на курс и на занятие. Это дополнительный слой поверх канона сборки из разделов выше.

Уровень курса (лежит в корне курса)

  • Хаб курса («Список занятий …») с входом, прогрессом и шкалой.
  • Памятка по технике безопасности «Памятка по технике безопасности.html» в «Вспомогательные материалы/» — обязательна в КАЖДОМ курсе (мини-курсы — в корне мини-курса).
  • Входное тестирование «Входное тестирование/<имя>/Анкета-входное-тестирование-*.html» — обязательна в каждом курсе.
  • Анкета обратной связи и (при необходимости) панель наставника/журнал прогресса (сквозная — через tl-portal-core.js).
  • Рабочие листы (интерактивные): «Рабочий лист самооценка навыков.html» + «Рабочий лист карточка профессии.html» — по 2 на курс.
  • Мини-игра-тренажёр «Игра верно или неверно.html» — карточки «Верно/Неверно» по теме курса.

Уровень занятия (папка «Занятие N/»)

  • Файл занятия (теория + практика + рефлексия + блокировка).
  • Методичка занятия «Методичка-занятия-NN.html» — для КАЖДОГО занятия (формат: шаги «Что делать / Что получится» .mt-step, чек-лист «Тема освоена, когда» .donecheck, «Совет» .tip).
  • Ссылка «Открыть методичку →» в файле занятия (блок .practlinks + CSS, якорь перед .tl-chk).
  • При необходимости — инструкция (пошаговое «руками», для аппаратных/программных операций).
Стандарт цвета курса. Стили всех курсов различаются ТОЛЬКО --accent и kicker; остальной CSS единый. Акценты: Электроника #167A4D, БПЛА #0E7490, КОМПАС-3D #4D008C, Робототехника #1F6FE0, VR #1F6FE0, C# #1F6FE0.

Привязка методички к уроку (эталон)

Чтобы урок ссылался на методичку, добавь CSS-классы .practlinks/.links/.link-row перед .tl-chk{margin-top:16px… и блок ссылки перед <div class="tl-chk" id="tlChk_XXX_lN">:

<div class="practlinks"><h3>Подробная инструкция (методичка)</h3>
  <div class="links"><div class="link-row" data-instr-link>
    <span>📘 Методичка занятия — пошаговое руководство</span>
    <a href="Методичка-занятия-NN.html" target="_blank">Открыть методичку →</a>
  </div></div></div>
