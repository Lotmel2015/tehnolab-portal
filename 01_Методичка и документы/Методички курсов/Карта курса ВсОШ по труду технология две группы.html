Курс «Олимпиадная подготовка к ВсОШ по труду (технологии)»

Профиль ТТиТТ · две траектории: «Базовый поток» (68 ч) и «Олимпийская группа» (102 ч)

Итог. Курс 2026/27 (сентябрь–май) состоит из двух групп с общим стартом (диагностика) и разным объёмом. «Базовый поток» — модуль А (68 ч) + банк заданий → цель — призёр муниципального этапа. «Олимпийская группа» — модуль А + модуль Б (102 ч) + летний интенсив (30 ч) → цель — региональный этап, выход на финал. Отбор в олимпийскую группу — по диагностике ≥ 50% и мотивации; внутри — регулярные тренировочные туры и порог 70% по разделам.

4. Методика и контроль

Обязательные элементы (обе группы): банк заданий с проверкой (5 заданий/день), тетрадь ошибок, спиральное повторение (3/10/30 дней), сверка с ключами, 1–2 тренировочных тура.
Только олимпийская группа: 5–6 туров в год, промежуточные зачёты по ГЛУБИНА-разделам (≥70%), проектный трек с репетицией защиты, участие в сборах/интенсиве.
