Занятие 32 · Ручная металлообработка

Разметка, резка, опиливание, сверление (на базе партнёра)

Апрель–май 2027 · 2 академических часа

ПрактикаИзделие из Ст3Итог: изделие из стали (заготовка)Статус: не пройдено
Главное. Слесарная практика на базе партнёра: разметка, резка ножовкой, опиливание и сверление — выполняем простое изделие из стали Ст3.

Карта занятия

1Слесарная базаВерстак, тиски, инструмент, ТБ
2РазметкаЧертилка, кернер, штангенциркуль
3ОбработкаРезка ножовкой, опиливание напильником, сверление
4КонтрольРазмеры, кромки, сборка по карте

Разбираем тему

  • Разметка металла: чертилка по линейке, кернер для отверстий, штангенциркуль для размеров.
  • Резка ножовкой по металлу: полотно по разметке, без перекосов, смазка.
  • Опиливание: напильник движется от себя, контроль угольником.
  • Сверление: керновка (засечка), фиксация в тисках, малые обороты, охлаждение.

Задание на занятии

  • Выполни разметку заготовки из Ст3 по чертежу.
  • Отрежь, опили и просверли отверстия.
  • Проверь размеры и качество кромок по карте контроля.
Результат занятия: Изделие-заготовка из стали Ст3 по карте контроля
Шпаргалка / критерии:
  • Работа в защитных очках: стружка летит от себя.
  • Сверлильный станок: деталь жёстко зафиксирована, руки на расстоянии.
  • Точность: штангенциркуль до 0,1 мм — проверяй каждый размер.
