1Пошагово — делай по порядку

1Пойми принцип Raycast

💡 Когда ты касаешься экрана, Unity пускает «луч» от камеры вглубь. Если луч попадает в распознанную плоскость — получаем точку, где ставить объект.

Что делать: Прочитай схему: касание → луч → пересечение с плоскостью → точка установки.

Что должно получиться
Понял, зачем луч и плоскость.
Почему луч, а не просто точка экрана? Экран — двумерный, а мир — трёхмерный. По одному касанию телефон не знает расстояния до поверхности, поэтому от камеры «выстреливается» луч, и движок смотрит, во что он врежется. Точка пересечения луча с распознанной плоскостью и есть место установки.

Луч летит от камерыТочка-«курсор» на плоскости (предпросмотр)
Луч попал в плоскостьОбъект появился в точке касания
2Настрой сцену под размещение

💡 Нужен объект, который будет «управлять» касаниями.

Что делать: На AR Session Origin добавь скрипт Placement (ниже). Он слушает касание и ставит объект.

Что должно получиться
Скрипт висит на AR Session Origin.
3Напиши код размещения

💡 Скрипт обрабатывает касание экрана, пускает луч и ставит объект в найденную точку.

Что делать: Создай скрипт Placement.cs и вставь код.

Код (копируй целиком)
using UnityEngine;
using UnityEngine.XR.ARFoundation;
using UnityEngine.XR.ARSubsystems;

public class Placement : MonoBehaviour {
    public GameObject objPrefab;
    private ARRaycastManager rayManager;
    void Awake() { rayManager = GetComponent(); }
    void Update() {
        if (Input.touchCount <= 0) return;
        var touch = Input.GetTouch(0);
        if (touch.phase != TouchPhase.Began) return;
        var hits = new System.Collections.Generic.List();
        if (rayManager.Raycast(touch.position, hits, TrackableType.PlaneWithinPolygon)) {
            var pose = hits[0].pose;
            Instantiate(objPrefab, pose.position, pose.rotation);
        }
    }
}
Что должно получиться
Коснулся стола — куб появился на столе.
4Закрепи объект якорем (Anchor)

💡 Без якоря куб может «уплыть», когда двигается камера. Якорь (AR Anchor) фиксирует объект в реальной точке мира.

Что делать: В коде после создания объекта добавь ему AR Anchor:

Код (копируй целиком)
var g = Instantiate(objPrefab, pose.position, pose.rotation);
g.AddComponent();
Что должно получиться
Куб стоит неподвижно, даже когда крутишь телефон.
5Сделай «следование» за пальцем

💡 Так удобнее: пока палец на экране, объект двигается, при отпускании закрепляется.

Что делать: Добавь в Update обработку фазы Moved (объект двигается за точкой) и Ended (закрепить).

Что должно получиться
Объект «едет» за пальцем и встаёт при отпускании.

2Типичные ошибки и как их исправить

Ошибка «Куб не появляется». Коснулся — ничего.
Как исправить: Проверь: Raycast manager (ARRaycastManager) есть на AR Session Origin, objPrefab привязан в Inspector, и на поверхности уже распознана плоскость.
Ошибка «Куб «уплывает»». Объект прыгает при движении камеры.
Как исправить: Добавь AR Anchor к объекту (см. шаг 4).
Ошибка «Объект падает/уходит вниз». Разместил, а куб стоит криво или проваливается.
Как исправить: Ставь объект только на горизонтальную плоскость и следи, чтобы его «низ» совпадал с точкой raycast. Разверни префаб так, чтобы основание объекта стояло на поверхности, а не центр.
