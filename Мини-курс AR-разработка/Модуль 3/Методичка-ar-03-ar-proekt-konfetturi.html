AR-проект: конфигуратор мебели

Подробное руководство для школьника: как делать, зачем и что должно получиться.

Модуль 03НачинающимПодробно
Цель модуля. Финальный проект: конфигуратор мебели. Выбираешь предмет в меню, ставишь его на пол, переносишь и убираешь. Как в приложениях для покупки мебели из IKEA!
Как всё связано. У всего конфигуратора один фундамент — Raycast из модуля 2. Размещение ищет плоскость, перемещение цепляет collider объекта, удаление ведёт список поставленных предметов (List). Поняв эти три приёма, ты сможешь собрать любое AR-приложение «расставь объекты по комнате».
ДействиеЧто используетРезультат
Разместить предметRaycast ищет плоскостьНовый объект появился по касанию
Переместить предметЛуч цепляет Collider объектаОбъект переехал на новое место

0Что понадобится

  • Проект из Модуля 2 — Там уже есть размещение по касанию.
  • 3 префаба мебели — Стул, стол, лампа (примитивы или модели).
  • UI-меню — Панель с кнопками.

1Пошагово — делай по порядку

1Подготовь 3 префаба мебели

💡 Нужны объекты, которые будем ставить. Сделай простые варианты из примитивов.

Что делать: Создай три префаба: Chair (куб+куб вместо спинки), Table (цилиндр-ножка + плоскость-столешница), Lamp (цилиндр+сфера). Помести в Resources.

Что должно получиться
Три префаба готовы.
2Сделай меню выбора

💡 Чтобы выбирать, какой предмет ставить, сделаем панель с тремя кнопками.

Что делать: В Canvas добавь горизонтальную панель с 3 Button (Стул, Стол, Лампа).

Что должно получиться
Меню в углу экрана с тремя кнопками.
3Напиши код меню и размещения

💡 Кнопки задают, какой префаб ставить; касание ставит его.

Что делать: Создай скрипт MenuAR.cs с методом SetItem(index) и используй Placement из прошлого модуля, но с выбором префаба.

Код (копируй целиком)
public class MenuAR : MonoBehaviour {
    public GameObject[] items;   // стул, стол, лампа
    public Placement placement;
    public void Pick(int i) { placement.objPrefab = items[i]; }
}
Что должно получиться
Выбрал «Стул» — теперь касание ставит стул.
4Добавь перемещение (drag)

💡 Размещённый предмет иногда нужно передвинуть.

Что делать: Когда касание попадает в уже размещённый объект с collider — двигай его за пальцем.

Код (копируй целиком)
void Update() {
  if (Input.touchCount <= 0) return;
  var touch = Input.GetTouch(0);
  var ray = Camera.main.ScreenPointToRay(touch.position);
  if (Physics.Raycast(ray, out var hit)) {
    if (touch.phase == TouchPhase.Began) grabbed = hit.collider.gameObject;
  }
  if (grabbed && (touch.phase == TouchPhase.Moved)) {
    // ставим объект на найденную плоскость поблизости
  }
}
Что должно получиться
Пойманный объект перемещается.
5Добавь удаление

💡 Чтобы убрать лишний предмет.

Что делать: Добавь кнопку «Удалить» — она убирает последний поставленный предмет.

Код (копируй целиком)
public void DeleteLast() {
    if (placed.Count > 0) { Destroy(placed[placed.Count-1]); placed.RemoveAt(placed.Count-1); }
}
Что должно получиться
Кнопка убирает последний объект.
6Собери и протестируй

💡 Финал AR-приложения.

Что делать: Собери APK и проверь на разных поверхностях и освещении.

Что должно получиться
Приложение работает на телефоне: выбираешь, ставишь, двигаешь, убираешь.

2Типичные ошибки и как их исправить

Ошибка «Выбранный предмет не тот». Ставится не то, что выбрал.
Как исправить: Проверь порядок items[] — он должен совпадать с индексами кнопок (0,1,2).
Ошибка «Нельзя передвинуть объект». Drag не работает.
Как исправить: У объекта должен быть Collider, а касание — попадать в него. Добавь Collider ко всем префабам.
Ошибка «Кнопка удаления не работает». Нажал «Удалить» — ничего.
Как исправить: Проверь, что ты ведёшь список размещённых объектов (List), добавляешь в него каждый новый предмет при размещении и отслеживаешь, что список не пустой, прежде чем удалять.
