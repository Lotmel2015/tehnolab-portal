# Технологическая лаборатория — портал и курсы

Статический сайт объединения «Технологическая лаборатория» (КГАОУ «Школа космонавтики», Железногорск) + электронные курсы по направлениям.

## Как опубликовать на GitHub Pages

### Вариант А. Без установки программ (GitHub Desktop) — рекомендуемый

1. Установите **GitHub Desktop** с официального сайта: https://desktop.github.com
2. Заведите аккаунт на **github.com** (бесплатно).
3. В GitHub Desktop: `File → Add local repository` — выберите эту папку
   (путь: `C:\Users\Lotmel\Desktop\Desktop\Техннологическая лаборатория`).
4. Снимите галочку если предлагают создать репозиторий — нажмите **Create repository**.
   - Repository name: например `tehnolab-portal`
   - Public или Private (для Pages подойдёт и то и другое; Public проще).
5. Сделайте первый коммит: слева внизу впишите сообщение («Первый коммит») → **Commit to main**.
6. Кнопка **Publish repository** → выберите GitHub → опубликуйте.
7. Откройте сайт на GitHub: репозиторий → **Settings** → **Pages** (в левом меню).
   - Source: `Deploy from a branch` → Branch: `main` → `/ (root)` → **Save**.
8. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/tehnolab-portal/`

> ВАЖНО: портал — это `Портал Технологическая лаборатория.html`. К сожалению, GitHub Pages
> автоматически открывает только файл `index.html`. Поэтому откройте сайт по адресу:
> `https://<ваш-логин>.github.io/tehnolab-portal/Портал%20Технологическая%20лаборатория.html`
> (или добавьте в корень папку `docs/` с index.html, см. ниже).

### Вариант Б. Чтобы открывался сразу главный файл (index.html)
Создайте в корне файл-перенаправление `index.html`:
```html
<!DOCTYPE html>
<meta charset="utf-8">
<title>Технологическая лаборатория</title>
<script>location.replace('Портал Технологическая лаборатория.html');</script>
```
И положите его рядом с порталом — тогда по адресу `https://<ваш-логин>.github.io/tehnolab-portal/`
сразу откроется портал. (Вместо этого можно переименовать портал в `index.html`, но тогда
нужно поправить внутренние ссылки на него.)

## Что внутри

Структура корня (после реструктуризации): исполняемые каталоги остаются на месте, документы распределены по папкам.

- `index.html` — редирект на портал (открывается GitHub Pages по умолчанию)
- `assets/` — изображения и стили (в т.ч. `icons-all-7.jpg`, `kompas-clean.jpg`)
- `00_Карта и статус проекта/` — «Сводка по проекту…», «Сводный конспект проекта…» (карта для ассистентов)
- `01_Методичка и документы/` — канон сборки курса, методички курсов, шаблоны
- `02 Чат А Ядро и портал/` … `02 Чат Г Публикация и git/` — каталоги рабочих чатов с манифестами зон ответственности
- `03_Отчеты и аналитика/` — «Анализ эффективности портала ТЛ», «Обратная связь сотрудников…»
- `ТЛ/` — методические материалы, пам-таки, концепции (в т.ч. портал и ядро в `ТЛ/ТЛ концепция/`)
- `ПД/`, `VR/` — служебные/вспомогательные материалы
- `Курс-VR-студия/`, `Курс-Робототехника/`, … — электронные курсы (взаимные ссылки с порталом)

## Примечания

- Данные пользователей хранятся в браузере (localStorage) — публикация на GitHub Pages
  сохраняет эту логику; для работы с любого устройства без потери данных потребуется
  серверная часть (см. «Инструкция сквозная регистрация ТЛ.md»).
- Крупные служебные папки (`node_modules`, `.gigatool`, папки `verify`) исключены через `.gitignore`.
- GitHub Pages публикует только то, что попало в коммит; после обновления файлов повторите
  коммит и push — изменения появятся автоматически (через 1–2 минуты).
