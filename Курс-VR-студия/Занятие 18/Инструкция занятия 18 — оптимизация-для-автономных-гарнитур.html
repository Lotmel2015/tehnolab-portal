Оптимизация для автономного шлема

Пошагово разбираем ограничения автономных шлемов, настраиваем LOD и батчинг, запекаем свет и профилируем FPS до и после.

· Занятие 18 · Модуль 5 · для 8–11 классов

Главное. Автономный шлем (как Pico) — это по сути мощный телефон: ресурсы ограничены. Сцена, которая «летает» на ПК, в шлеме может тормозить и вызывать укачивание. Сегодня научишься держать стабильные 90 FPS: LOD, запечённый свет и профилирование.

РесурсПочему важно

Памятьбольшые текстуры выгружаются и тормозят

Совет. Цель — стабильные 90 FPS. Если проседает — укорачивай дальность прорисовки, уменьшай детализацию и число источников света.

LOD и батчинг

LOD (Level of Detail) — у дальних объектов показываем упрощённые копии, а вблизи — детальные. Так ГП не тратит силы на то, чего не видно. Батчинг группирует похожие объекты в один вызов отрисовки.

Настрой LOD

  1. Создай 2–3 уровня модели (детальная LOD0, средняя LOD1, простая LOD2).
  2. Выдели объект → Add Component → LOD Group.
  3. Перетащи варианты в слоты и задай расстояния переключения.
  4. Проверь: вблизи детальная, издалека — простая.
Совет. В панели Occlusion Culling можно дополнительно не рисовать скрытые объекты — ещё один способ сэкономить ресурсы.

Запечённое освещение

Динамический свет пересчитывается каждый кадр — это дорого. Запечённый (Baked) свет считает освещение один раз и «запекает» его в текстуры. В статичной сцене это почти бесплатно во время игры.

  1. Пометь объекты сцены статичными (галочка Static вверху объекта).
  2. В Window → Rendering → Lighting включи Baked Global Illumination.
  3. Нажми Generate Lighting (запекание).
  4. Проверь, что источники света либо статичные (запечённые), либо динамических немного.
Важно. Запекание требует времени нажать Generate Lighting. Не забудь повторно запечь после изменения геометрии сцены.

Профилируем FPS

using UnityEngine; public class FpsCounter : MonoBehaviour
{ private float fps; void Update() { fps = 1f / Time.unscaledDeltaTime; Debug.Log("FPS: " + Mathf.Round(fps)); }
}

Сравни до и после

  1. Повесь FpsCounter и запиши FPS до оптимизации.
  2. Примени LOD и запечённый свет.
  3. Запиши FPS после и сравни — запомни разницу.
  4. Открой Window → Profiler, чтобы найти узкие места (ГП/ЦП).
Совет. Записывай FPS на самой «тяжёлой» точке сцены (где много объектов), а не в пустом углу.

Домашнее задание

Оптимизируй свою сцену из практикума и запиши FPS до/после — это пригодится для защиты проекта.
