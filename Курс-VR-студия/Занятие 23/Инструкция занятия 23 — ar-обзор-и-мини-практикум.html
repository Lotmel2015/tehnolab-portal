Дополненная реальность: AR Foundation

Пошагово разбираем отличие AR от VR, устанавливаем AR Foundation, распознаём маркер-изображение и размещаем 3D-объекты на плоскости.

· Занятие 23 · Модуль 6 · для 8–11 классов

Главное. AR не заменяет реальный мир, а дополняет его объектами: наводишь камеру телефона на пол — и «появляется» модель. Сегодня соберёшь проект с AR Foundation, научишься распознавать маркер-картинку и размещать 3D-объект на плоскости. Получится живая демка для защиты.

Совет. AR удобно показывать на защите: навёл телефон на пол — и на полу «появилась» твоя 3D-модель.

Устанавливаем AR Foundation

  1. В Package Manager установи пакеты AR Foundation, ARCore XR Plugin (Android) и ARKit XR Plugin (iOS).
  2. В Build Settings включи платформу Android (для телефона) или iOS.
  3. В XR Plug-in Management включи ARCore для Android.
Важно. AR Foundation работает на телефоне с камерой. Для ПК/шлема VR эта тема не подходит — это отдельное направление.

Настраиваем AR-сессию и плоскость

  1. Добавь в сцену AR Session (Window → XR → AR Session) — управляет камерой AR.
  2. Добавь AR Session Origin.
  3. Добавь на Origin компонент AR Plane Manager: при наведении камеры на пол/стол будут находиться плоскости.
  4. Добавь AR Raycast Manager — для касаний по найденной плоскости.
Совет. Родительский объект AR манипуляций — plane visualizer — наглядно показывает найденные плоскости.

Распознаём маркер-изображение

  1. Подготовь картинку-маркер (чёткую, с контрастным рисунком).
  2. Добавь компонент AR Tracked Image Manager на AR Session Origin.
  3. Создай Reference Image Library и добавь туда своё изображение.
  4. Укажи в AR Tracked Image Manager эту библиотеку.
  5. При наведении камеры на маркер появится «привязанный» к нему объект.

Размещаем объект по касанию

using UnityEngine.XR.ARFoundation;
using UnityEngine.XR.ARSubsystems; public class PlaceOnPlane : MonoBehaviour
{ public GameObject prefab; private ARRaycastManager raycast; private GameObject placed; void Start() { raycast = GetComponent(); } void Update() { if (Input.touchCount > 0 && Input.GetTouch(0).phase == TouchPhase.Began) { if (raycast.Raycast(Input.GetTouch(0).position, new System.Collections.Generic.List(), TrackableType.PlaneWithinPolygon)) { if (placed != null) Destroy(placed); placed = Instantiate(prefab, /*позиция из хита*/ transform.position, transform.rotation); } } }
}
  1. Создай скрипт PlaceOnPlane, повесь на AR Session Origin.
  2. Перетащи модель (prefab) в поле prefab.
  3. Собери APK, установи на телефон, наведи камеру на маркер/плоскость и коснись — модель появится.
