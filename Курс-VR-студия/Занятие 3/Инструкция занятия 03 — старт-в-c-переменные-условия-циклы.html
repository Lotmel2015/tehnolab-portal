Как устроена программа на C#

Программа — это последовательность команд. Есть ввод (данные от пользователя), обработка (переменные и условия) и вывод (результат на экран).

Важно. Типы в C# смешивать нельзя: в переменную int нельзя положить текст. Компилятор сразу сообщит об ошибке — это не «поломка», а помощь.

Объявление переменной: int score = 0; — «создай коробку с именем score, в ней целое число, положи туда 0».

Ввод и вывод данных

Console.WriteLine("Как тебя зовут?");
string name = Console.ReadLine();
Console.WriteLine("Привет, " + name + "!");
  1. Console.WriteLine(...) — вывести текст и перейти на новую строку.
  2. Console.ReadLine() — ждать, пока пользователь введёт текст и нажмёт Enter.
  3. Чтобы получить число из строки: int.Parse(Console.ReadLine());
Совет. ReadLine всегда возвращает строку. Если нужно число — не забывай int.Parse(...).

Условия if/else

int age = int.Parse(Console.ReadLine());
if (age >= 12) { Console.WriteLine("Можно в VR-лабораторию!");
} else { Console.WriteLine("Подрасти ещё чуть-чуть.");
}

Условие решает, какой блок кода выполнить. Сравнения: ==, !=, >, <, >=, <=.

Циклы while и for

// считаем от 1 до 5
for (int i = 1; i <= 5; i++) { Console.WriteLine(i);
} // повторяем, пока условие верно
int x = 0;
while (x < 3) { Console.WriteLine("Идём дальше"); x++;
}
Совет. Почти любую игровую механику можно свести к этим трём кирпичикам: переменные, условия, циклы.
