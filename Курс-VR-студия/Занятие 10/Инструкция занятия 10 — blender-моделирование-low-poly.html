Моделируем low-poly: экструзия и модификаторы

Пошагово учимся экструзии и Loop Cut, работаем с модификаторами и моделируем настоящие объекты: дерево, стул и ящик с правильной топологией.

· Занятие 10 · Модуль 4 · для 8–11 классов

Главное. Low-poly — это модели из небольшого числа полигонов, идеальные для VR: они легко «летают» в шлеме. Сегодня ты освоишь два главных инструмента моделирования — экструзию (E) и Loop Cut (Ctrl+R) — и соберёшь своё первое дерево, стул и ящик.

Object Mode и Edit Mode

В Object Mode объект двигают, вращают и масштабируют целиком. В Edit Mode (Tab) редактируют его внутreннюю структуру — вершины, рёбра, грани. Именно Edit Mode нужен для лепки модели.

Совет. В Edit Mode выбирай грани (клавиша 3) — так удобнее всего «вытягивать» детали экструзией.

Экструзия: из куба — деталь

Как это работает

  1. В Edit Mode (Tab) выбери верхнюю грань куба (клавиша 3).
  2. Нажми E и потяни вверх — грань «вытянется», появится вторая коробка.
  3. ЛКМ — применить, ПКМ — отменить.
  4. Повтори 2–3 раза, чтобы получить «столбик» с уступами.
Совет. Экструзия — способ «вырастить» из простой коробки сложные формы: башню, ножку стола, ручку.

Loop Cut: делим модель на части

  1. В Edit Mode нажми Ctrl+R (Loop Cut).
  2. Надведи курсор на грань — появится оранжевое кольцо.
  3. ЛКМ поставь его, затем ПКМ/ЛКМ, чтобы зафиксировать.
  4. Теперь на модели есть дополнительные грани для экструзии деталей.
Важно. Loop Cut добавляет «разрезы», чтобы потом вытягивать детали по частям. Без него экструзия «работает» грубо.

Практика: дерево, стул и ящик

Низкополигональное дерево

  1. Куб → в Edit Mode выдели верхнюю грань → E — ствол кверху.
  2. Добавь конус (Shift+A → Mesh → Cone) — крона.
  3. Соедини: ствол и крона рядом.

Стул

  1. Куб → Loop Cut по горизонтали и вертикали.
  2. Экструзией сделай ножки (4 нижних ребра вниз).
  3. Verify: ножки на одном уровне с плоскостью пола.

Ящик (правильная топология)

  1. Куб, Loop Cut, вытяни верхнюю часть — крышку.
  2. Старайся, чтобы грани были «чистыми», без задвоений.

Модификаторы для скорости

Модификатор меняет модель автоматически. Самый полезный новичку — Subdivision Surface: сглаживает сетку и делает модель мягче, не рисуя вручную.

  1. Выбери объект → панель модификаторов (гаечный ключ).
  2. Добавь Subdivision Surface, увеличь Levels.
  3. Чтобы сгладилось правильно, сначала сделай Loop Cut (Ctrl+R) у границ.
Совет. Модификатор меняет модель «на лету». Примени его (Apply) только когда результат устраивает.
