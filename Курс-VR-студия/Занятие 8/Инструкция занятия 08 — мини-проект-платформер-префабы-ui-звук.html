Canvas и UI: счёт очков

Canvas — слой интерфейса поверх сцены. В него кладут текст, кнопки, переключатели. Чтобы счёт обновлялся, скрипт получает ссылку на Text и меняет его.

Шаг 1. Создай интерфейс

  1. В меню: GameObject → UI → Canvas (появится с Text внутри).
  2. Настрой Text: шрифт крупный, текст «Очки: 0», позиция в верхнем левом углу.

Шаг 2. Свяжи счёт со скриптом

  1. Создай скрипт ScoreManager с полем public Text scoreText и методом Add(int).
  2. Перетащи на скрипт объект Text — теперь он «видит» интерфейс.

Монеты: префаб + счёт + звук

Шаг 1. Сделай префаб монеты

  1. Добавь в сцену Sphere, назови Coin, покрась в жёлтый/золотой.
  2. Добавь Sphere Collider и отметь Is Trigger.
  3. Создай скрипт Coin: при вхождении игрока добавляет очки и исчезает.
  4. Перетащи Coin в Project — получится префаб. Разложи по уровню копии.
using UnityEngine;
using UnityEngine.UI; public class Coin : MonoBehaviour
{ public Text scoreText; public AudioClip pickup; private int score = 0; void OnTriggerEnter(Collider other) { score += 1; scoreText.text = "Очки: " + score; AudioSource.PlayClipAtPoint(pickup, transform.position); Destroy(gameObject); }
}
Важно. У монеты должен быть только Trigger-коллайдер и НЕ должно быть Rigidbody — иначе она будет падать и откатываться.

Музыка и звук

  1. Добавь на камеру или отдельный объект компонент AudioSource.
  2. Перетащи в поле AudioClip файл музыки, отметь Loop — фон зациклится.
  3. Для звука сбора используй AudioSource.PlayClipAtPoint(...) или второй AudioSource.
Совет. Звук можно сделать самому: в Unity записывают короткие клипы через микрофон или берут бесплатные библиотеки (например, OpenGameArt — бесплатно).

Собираем уровень

  1. Построй из кубов-платформ маршрут: старт → препятствия → финиш.
  2. Разложи 5–8 монет по траектории.
  3. Добавь триггер-зону «финиш» (как на занятии 07).
  4. Настрой камеру, чтобы было удобно играть.
  5. Запусти и пройди уровень сам — проверь, что всё «играется».
Совет. Хороший уровень — тот, который можно пройти без «вылета» и с удовольствием. Если монета недосягаема — это баг дизайна, а не игры.

Защита: 3 минуты

  1. Покажи игру в окне Game и объясни, что делает каждый элемент.
  2. Назови 2–3 скрипта и зачем они нужны.
  3. Скажи, что получилось лучше всего и что доделаешь дома.
Совет. Защита — это не экзамен, а возможность показать работу. Отвечай коротко и по делу: «Сделал сцену, монеты, счёт, звук».
