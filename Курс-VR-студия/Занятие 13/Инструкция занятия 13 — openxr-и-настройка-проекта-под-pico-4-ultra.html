Что такое OpenXR

OpenXR — открытый стандарт, по которому игра получает данные со шлема и контроллеров: позицию, поворот, нажатия. Unity поддерживает его «из коробки» через XR Plug-in Management, поэтому одна игра работает и на Pico, и на других совместимых шлемах.

Устанавливаем XR Interaction Toolkit

  1. Открой Unity: Window → Package Manager.
  2. В поиске найди XR Interaction Toolkit (пакет Unity).
  3. Установи последнюю совместимую версию и дождись завершения.
  4. При появлении «Sample scenes» выбери одну сцену для теста (например, XRI Basic Interactions).
Совет. Примеры (Samples) XR Toolkit дают готовую сцену с телепортом и захватом — удобно проверить связку до написания своего кода.

Настраиваем XR Plug-in Management

Шаг 1. Включи поддержку XR

  1. Меню Edit → Project Settings → XR Plug-in Management.
  2. Включи плагин для Android (галочка).
  3. Если есть вкладка OpenXR — включи её и добавь Pico XR (или OpenXR feature), если доступно.

Шаг 2. Переключи платформу на Android

  1. File → Build Settings → выбери Android → Switch Platform.
  2. Дождись, пока Unity переключит платформу (это может занять несколько минут).
Важно. Без включённого плагина OpenXR для Android проект не сможет собрать XR-сборку под Pico. Проверяй обе настройки перед сборкой.

Проверяем связку с Pico

  1. Открой тестовую XR-сцену (пример XR Toolkit).
  2. Запусти сцену в шлеме до полной сборки APK — беспроводным стримингом через Pico Connect: установи Pico Connect на ПК (picoxr.com/software/pico-link) и в шлеме (Pico Store), подключи оба к одному Wi-Fi.
  3. Нажми в Unity Play: сцена запустится в редакторе, а Pico Connect будет транслировать её в шлем (режим PC VR / Desktop).
  4. Надень шлем: сцена должна появиться, контроллеры — реагировать на движение.
  5. Если «картинка не смотрит за головой» — проверь включение XR и трекинг.
Важно. Файл APK для установки на шлем без ПК соберём на занятии 16. Пока используем стриминг Pico Connect — так удобно проверять сцену на шлеме без долгой сборки.
Совет. Первый нормальный показ сцены в шлеме — важная веха. Запомни это ощущение: дальше будет проще строить именно под VR.
