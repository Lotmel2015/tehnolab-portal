Анимация в Unity: Animator и Blend Tree

Пошагово разбираем компонент Animator, состояния и переходы, Blend Tree для плавности и практикуемся: вращение, открытие двери и плавное появление меню.

· Занятие 19 · Модуль 6 · для 8–11 классов

Главное. Анимация оживляет мир: дверь открывается, куб вращается, меню плавно появляется. В Unity этим управляет Animator — компонент, который переключает состояния по правилам. Сегодня ты сделаешь три простые анимации и разберёшься, как Blend Tree смешивает их для плавности.

Компонент Animator

Animator — компонент на объекте, который управляет его анимациями. Он работает с Animator Controller — файлом-диаграммой состояний и переходов между ними.

  1. Выбери объект → Add Component → Animator.
  2. Создай Animator Controller: правая кнопка в Project → Create → Animator Controller.
  3. Перетащи контроллер в поле Animator Controller.

Состояния и переходы

В окне Animator (меню Window → Animation → Animator) видно состояния (состояния-файлы клипов) и стрелки переходов. Например: Idle → Open — «когда дверь открывается».

Практика: анимация вращения

  1. Создай Animation Clip: меню Window → Animation → кнопка Create.
  2. Выбери объект, добавь ключ поворота по Y на 0°, затем на 360° через 2 секунды.
  3. Перетащи клип в Animator как состояние Default.
  4. Запусти игру — объект вращается.
Совет. Ключевые кадры (Keyframes) задаются в окне Animation: ставишь значения на разных моментах времени — Unity плавно «дорисовывает» между ними.

Открытие двери через Blend Tree

Blend Tree плавно смешивает два и более клипа по одному параметру. Для двери: значение 0 — закрыто, 1 — открыто, между ними — плавное вращение.

  1. В Animator: правой кнопкой → Create State → From New Blend Tree.
  2. Дважды кликнув по Blend Tree, добавь 2 клипа: DoorClosed и DoorOpen.
  3. Добавь параметр open (Float).
  4. Из скрипта меняй animator.SetFloat("open", value) — дверь плавно открывается/закрывается.
public class Door : MonoBehaviour
{ private Animator anim; void Start() { anim = GetComponent(); } void OnTriggerEnter(Collider other) { anim.SetFloat("open", 1f); } void OnTriggerExit(Collider other) { anim.SetFloat("open", 0f); }
}

Плавное появление меню

  1. Создай Animation для панели меню: вращение/масштаб от 0 к 1.
  2. Подключи Blend Tree по параметру show.
  3. В кнопке «Старт» меню вызывай SetFloat("show", 1) — панель плавно появится.
  4. Проверь в шлеме, что меню «выезжает» без рывков.
Совет. Плавные появления/исчезновения (а не мгновенное переключение) делают VR-интерфейс приятнее и комфортнее для глаз.
