Сборка APK для PICO 4 Ultra

Пошаговая инструкция: как из готового проекта Unity собрать установочный файл .apk именно для шлема PICO 4 Ultra (ARM64 + IL2CPP + Vulkan) и что проверить в Player Settings.

Главное. APK — установочный файл Android. Чтобы шлем PICO 4 Ultra его запустил, проект должен быть собран под Android (вкладка Android в Build Settings), с архитектурой ARM64, компилятором IL2CPP и графическим API Vulkan. Тогда через File → Build Settings → Build Unity создаст файл .apk, который ставится на шлем через ADB (USB/Wi-Fi) или файловый менеджер.

01Подготовка: что уже должно быть

Эта инструкция — про саму сборку. Считаем, что окружение уже настроено (иначе сначала прочитай инструкции по ссылкам ниже):

  • Установлена Unity 6 LTS (рекомендуется Unity 6.3 LTS) с модулями Android;
  • В проект добавлен PICO Unity Integration SDK (пакет PICO XR), включён OpenXR в XR Plug-in Management, выбран профиль контроллеров Pico;
  • Сцена готова (XR Origin, телепортация, захват объектов), проект открыт и не даёт ошибок в консоли.

02Сборка APK: по шагам

1Откройте Build Settings

В меню выберите File → Build Settings. Справа откроется список платформ.

2Переключитесь на Android

Выберите платформу Android в списке слева и нажмите кнопку Switch Platform.

Первое переключение занимает 1–3 минуты: Unity перенесёт ассеты под другую платформу. Пока идёт переключение — не закрывайте окно.

Внимание. Сборка под ПК, macOS или WebGL не подходит для шлема PICO 4 Ultra — нужна именно платформа Android. Сборка под другие платформы пригодится на других занятиях, но не для запуска на шлеме.
3Настройте Player Settings

В Build Settings нажмите кнопку Player Settings — откроется окно Project Settings → Player. Проверьте значения из таблицы ниже.

Минимальный обязательный набор для PICO 4 Ultra:

НастройкаГдеЗначение для PICO 4 UltraПочему
ArchitectureOther Settings → Target ArchitecturesARM64шлем работает на 64-битном процессоре Snapdragon; 32-бит (ARMv7) не подходит
Scripting BackendOther Settings → ConfigurationIL2CPPкомпилирует C# в быстрый машинный код; Mono на шлеме медленнее
Minimum API LevelOther Settings → IdentificationAndroid 10.0 (API 29) или вышеминимальный порог, требуемый PICO SDK для современных функций
Graphics APIsOther Settings → Graphics APIs (Android)Vulkan (и отключить Auto Graphics API)Vulkan хорошо работает на чипе Snapdragon и нужен для OpenXR
Package nameOther Settings → Identification → Package Nameуникальное имя, напр. com.sputnik.myvrteamуникальный идентификатор приложения; два разных проекта не должны совпадать
4Убедитесь, что сборка в формат APK (не App Bundle)

В Build Settings снизу в поле Build App Bundle (Google Play) галочка должна быть выключена. Так Unity соберёт обычный .apk, который легко поставить на шлем вручную.

Совет. Если галка включена, Unity сделает .aab, который шлем «в лоб» не ставит — для PICO нам нужен именно APK.
5Нажмите Build и выберите папку

Нажмите кнопку Build. Unity попросит выбрать папку и имя файла — например, MyVRteam.apk. Первая сборка долгая (5–20 минут): Unity ставит Gradle, компонует код IL2CPP, скачивает зависимости. Последующие сборки быстрее.

Если вы нажали Build And Run и шлем подключён по USB — Unity соберёт и сразу установит APK на шлем.

Запомни порядок. Build Settings → Android → Switch Platform → Player Settings (ARM64, IL2CPP, API 29, Vulkan) → Build App Bundle выкл → Build → готов APK.

03Где лежит собранный файл

Unity создаёт в выбранной папке файл *.apk. Проверить, что это правильная сборка, можно:

  • файл имеет расширение .apk и весит обычно от 30 до 200 МБ;
  • если при сборке не было ошибок, в консоли Unity нет строк с Error;
  • имя файла совпадает с тем, что вы указали при Build.

04Что дальше: установка на шлем

Готовый APK ставится на PICO 4 Ultra тремя основными способами. Подробная пошаговая инструкция по установке — по ссылке:

Все способы установки APK на PICO 4 Ultra (ADB по USB, по Wi-Fi, файловый менеджер)Инструкция: установка APK на Pico 4 Ultra

Кратко:

  • ADB по USB: включите режим разработчика и отладку USB на шлеме, подключите кабель, выполните adb install MyVRteam.apk;
  • ADB по Wi-Fi: adb connect 192.168.1.50:5555, затем adb install -r MyVRteam.apk;
  • Без кабеля: скопируйте APK в память шлема и нажмите на него в файловом менеджере.
Перед установкой: включите режим разработчика и разрешите установку из неизвестных источников. При первом подключении разрешите доверять этому компьютеру.

05Частые ошибки сборки и их решение

Сообщение / признакПричинаРешение
«No Android SDK found»не установлены модули Android для UnityВ Unity Hub добавьте к своей версии Unity модули Android Build Support, SDK & NDK Tools, OpenJDK
Ошибка Gradle при первой сборкеUnity подгружает зависимости Gradle, падает сетьповторите Build после перезапуска; проверьте соединение; при необходимости включите куратор — спросите педагога
Собрал, но шлем пишет «не удалось установить» / signedсборка не в APK, или файл повреждён при копированиипроверьте, что Build App Bundle выключен, и переустановите по ADB: adb install -r MyVRteam.apk
«No matching device found» при Build And Runшлем не опознан по USBвключите отладку USB, подключите кабель, разрешите доверие компьютеру, проверьте adb devices
Приложение запускается, но «чёрный экран»настройки Graphics API / XR не тепроверьте Vulkan и что в XR Plug-in Management включён OpenXR + профиль Pico
Совет. Самый быстрый способ убедиться, что сборка удалась, — команда adb install -r путь/к/файлу.apk и запуск приложения на шлеме.
