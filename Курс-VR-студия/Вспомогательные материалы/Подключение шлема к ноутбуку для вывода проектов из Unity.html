Подключение шлема PICO 4 Ultra к ноутбуку

Пошаговая инструкция: как соединить шлем VR с ноутбуком (по USB-кабелю или Wi-Fi) и вывести на него проект, сделанный в Unity, — через стриминг из редактора или установку APK.

Главное. Шлем PICO 4 Ultra подключается к ноутбуку по USB-кабелю (надёжно, для копирования и установки APK) или по Wi-Fi (удобно, для стриминга сцены прямо из Unity через Pico Connect). Чтобы ноутбук «видел» шлем, один раз включите на шлеме режим разработчика и отладку USB; ПК и шлем должны быть в одной Wi-Fi-сети. Дальше — два пути: быстро показать сцену стримингом (без сборки) либо собрать APK и установить его на шлем.

01Подготовка: что нужно сделать один раз

Эти шаги общие для всех способов подключения. Выполните их один раз — дальше ноутбук и шлем будут «знакомы» и будут работать.

1Включите режим разработчика на шлеме

Почти все способы подключения к ПК требуют режима разработчика. Включите его так:

  1. В шлеме откройте Настройки (шестерёнка в правом нижнем углу, рядом с часами и Wi-Fi).
  2. Перейдите в раздел «Основные» → «Информация» (в некоторых версиях прошивки — «О системе» / «Об устройстве»).
  3. Найдите пункт «Версия ПО» и быстро нажмите на него 7–8 раз подряд, пока не появится уведомление о включении режима разработчика.
  4. В меню слева появится раздел «Разработчик» — откройте его.
  5. Включите переключатель «Отладка USB» (USB debugging).
Совет. Для способов с ПК у пункта «USB-подключение» выберите режим «Передача файлов» (MTP), а не «Только зарядка».
2Подключите ноутбук и шлем к одной сети

Для Wi-Fi-подключения оба устройства должны быть в одной локальной сети (один роутер / одна Wi-Fi-сеть). Лучше всего — диапазон 5 ГГц или Wi-Fi 6: он быстрее и стабильнее для передачи картинки.

Важно для стриминга. Если Wi-Fi слабый (только 2,4 ГГц, много помех), картинка в шлеме будет «мылиться» и тормозить. Для стриминга из Unity нужна стабильная скорость от 30–50 Мбит/с.
3Проверьте, что Unity настроена под Pico

Перед выводом проекта убедитесь, что ваш проект уже «VR-ready»: установлены пакеты XR Plug-in Management, OpenXR Plugin, PICO Unity Integration SDK, включён OpenXR в XR Plug-in Management и выбран профиль контроллеров Pico. Если нет — сначала пройдите занятие 13 «OpenXR и настройка проекта под Pico 4 Ultra».

02Способ А — подключение по USB-кабелю

Самый надёжный способ. По USB-кабелю ноутбук видит шлем как устройство: можно копировать файлы, устанавливать APK, смотреть логи. Нужен кабель USB-C → USB-A (или USB-C), который поддерживает передачу данных (не только зарядку), и инструмент ADB.

1Подключите кабель

Соедините шлем и ноутбук кабелем. На шлеме при подключении выберите режим «Передача файлов» (MTP), если система спросит. В Windows шлем появится как съёмный диск.

2Разрешите доверие компьютеру

При первом подключении на шлеме появится запрос «Разрешить отладку USB?» с ключом доверия. Поставьте галочку «Всегда разрешать с этого компьютера» и нажмите Разрешить.

3Проверьте ADB

Откройте терминал (PowerShell или командную строку) в папке с adb.exe и выполните:

adb devices

В ответ вы должны увидеть устройство со статусом device (не unauthorized и не пусто):

List of devices attached
1P4U1234567890    device
Совет. Если статус unauthorized — на шлеме не нажали «Разрешить». Если список пуст — проверьте кабель (нужен data-кабель), режим «Передача файлов» и что включена отладка USB.
4Установите свой APK

Если вы уже собрали APK (см. раздел «Вывод из Unity»), установите его на шлем командой:

adb install -r MyVRteam.apk

Флаг -r позволяет переустановить приложение поверх старой версии, не теряя данные.

Запомни. USB — это «провод»: кабель + режим разработчика + отладка USB + разрешение доверия = надёжное подключение для установки и отладки.

03Способ Б — подключение по Wi-Fi

Беспроводной способ. Удобен для стриминга сцены из Unity прямо в шлем (режим PC VR) и для установки APK без кабеля. Два инструмента: Pico Connect (фирменное приложение Pico для ПК и шлема) и ADB по Wi-Fi.

Вариант Б1 — Pico Connect (стриминг и передача файлов)

1Установите Pico Connect на ноутбук

Скачайте и установите Pico Connect для ПК с официальной страницы: picoxr.com/software/pico-link. Убедитесь, что на шлеме установлено приложение Pico Connect (оно есть в Pico Store).

Официальные источники. Скачивайте Pico Connect только с официального сайта Pico или из Pico Store. Не используйте сторонние сборки и «активаторы».
2Соедините устройства

Убедитесь, что ноутбук и шлем в одной Wi-Fi-сети. Запустите Pico Connect на ноутбуке и в шлеме. В приложении (или на шлеме) выберите ваш компьютер из списка доступных и нажмите Подключить. При первом подключении подтвердите соединение на обоих устройствах.

3Выберите режим работы

В Pico Connect доступны режимы Desktop (вернуть рабочий стол ноутбука) и PC VR (полноценная виртуальная реальность — SteamVR/OpenXR). Для вывода сцены Unity выберите нужный режим:

  • Desktop — в шлеме виден экран ноутбука (можно посмотреть окно Game view Unity);
  • PC VR — сцена отображается в шлеме как полноценное VR-приложение с трекингом головы и рук.
4Альтернатива: передача файлов через Pico Connect

В Pico Connect есть функция передачи файлов между ноутбуком и шлемом. Ею можно перекинуть APK в память шлема, а затем установить его из файлового менеджера AnExplorer или встроенного проводника Pico.

Вариант Б2 — ADB по Wi-Fi (установка APK без кабеля)

1Найдите IP-адрес шлема

В шлеме: Настройки → Wi-Fi, нажмите на подключённую сеть и посмотрите IP-адрес (например, 192.168.1.50).

2Подключитесь по ADB

На ноутбуке (шлем и ноутбук в одной сети) выполните:

adb connect 192.168.1.50:5555

Ответ connected to 192.168.1.50:5555 означает успех. Проверьте: adb devices — шлем должен быть в списке со статусом device.

3Установите APK 
adb install -r MyVRteam.apk
Внимание. При беспроводном подключении шлем и ноутбук должны быть в одной сети, а на шлеме — включена отладка USB (некоторые версии прошивки требуют разовое USB-подключение для доверия).
Запомни. Wi-Fi — это «рация»: одна сеть + Pico Connect (стриминг/файлы) или ADB по IP (установка без кабеля). Для стриминга нужен быстрый Wi-Fi (5 ГГц / Wi-Fi 6).

04Как вывести проект из Unity

Когда шлем подключён, есть два пути показать свою сцену. Выбирайте по задаче.

СценарийЧто делаемКогда подходит
Стриминг из редактораИграем сцену в Unity (кнопка Play) и транслируем картинку в шлем через Pico Connect — режим Desktop или PC VRБыстрый предпросмотр, отладка, демонстрация механики «вживую» с ноутбука; не требует сборки APK
Сборка APK и установкаСобираем проект в .apk (Android, ARM64, IL2CPP, Vulkan) и устанавливаем на шлем по USB или Wi-FiГотовый продукт, запуск без ноутбука, несколько шлемов, выставка/презентация

Путь 1 — стриминг из Unity (без сборки)

1Запустите сцену в редакторе

Откройте проект в Unity и нажмите Play. Сцена запустится в редакторе (окно Game view).

2Соединитесь через Pico Connect

Запустите Pico Connect на ноутбуке и в шлеме, соедините устройства (см. Способ Б, вариант Б1).

3Выберите режим

В Pico Connect выберите Desktop, чтобы увидеть в шлеме экран ноутбука (в т.ч. окно Game view), или PC VR с запущенным SteamVR — для полноценного VR-вывода с трекингом.

Ограничение. Стриминг требует мощного ноутбука (видеокарта уровня RTX 2060+ для приемлемой частоты кадров) и быстрого Wi-Fi. Для 12 шлемов одновременно этот способ не подходит — там нужна сборка APK.
Когда использовать. Педагогу удобно: показать сцену ученика на проекторе и «изнутри» в шлеме одновременно, быстро проверить механику без установки APK на все шлемы.

Путь 2 — сборка APK и установка

1Соберите APK

В Unity: File → Build Settings → платформа Android → Switch Platform → Player Settings (ARM64, IL2CPP, API 29+, Vulkan, Build App Bundle выкл) → Build.

Полная пошаговая инструкция по сборкеСборка APK для PICO 4 Ultra
2Установите на шлем

По USB: adb install -r MyVRteam.apk. По Wi-Fi: adb connect 192.168.1.50:5555 затем adb install -r MyVRteam.apk. Либо через файловый менеджер на шлеме (AnExplorer / проводник Pico).

Вывод. Хочешь быстро показать сцену — стриминг (Pico Connect). Хочешь готовый продукт на шлеме — сборка APK + установка.

07Чек-лист перед занятием

  • На шлеме включён режим разработчика и отладка USB.
  • USB-режим шлема — «Передача файлов» (MTP).
  • Ноутбук и шлем — в одной Wi-Fi-сети (лучше 5 ГГц / Wi-Fi 6).
  • На ноутбуке установлены: ADB, Pico Connect, Unity 6 LTS с проектом, настроенным под Pico (OpenXR + PICO SDK).
  • Есть USB data-кабель (не только зарядка).
  • Для стриминга — ноутбук с видеокартой RTX 2060+ и быстрый Wi-Fi.
  • Для готового продукта — собран APK (ARM64 + IL2CPP + Vulkan, Build App Bundle выкл).
  • Проверка: adb devices → device; adb install -r → Success.
