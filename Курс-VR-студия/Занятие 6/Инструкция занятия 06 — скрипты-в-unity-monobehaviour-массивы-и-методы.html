Оживляем объекты: первый скрипт в Unity

Пошагово создаём скрипт C# в Unity, разбираем Start и Update, учимся управлять Transform из кода и делаем вращающийся куб.

· Занятие 06 · Модуль 3 · для 8–11 классов

Главное. Скрипт — это способ «оживить» объект. Сегодня ты напишешь свой первый скрипт на C# в Unity: разберёшься, зачем нужны Start() и Update(), научишься менять Transform из кода и превратишь обычный куб в вращающийся объект. Главное — понять цикл: Start() выполняется один раз, Update() — каждый кадр.

Создаём первый скрипт

  1. В панели Project нажми правой кнопкой → Create → C# Script.
  2. Назови его Rotator (имя файла и класса должны совпадать).
  3. Перетащи скрипт на куб в сцене — у куба появится компонент Rotator.
  4. Двойной клик по скрипту откроет редактор кода.
Важно. Имя скрипта и имя класса должны совпадать точно, включая регистр. Иначе Unity не сможет его подключить.

Start() и Update() — жизненный цикл объекта

МетодКогда вызываетсяПример использования
Start()один раз при появлении объектазадать начальные значения
Update()каждый кадрреакция на нажатия, движение
Совет. Update вызывается десятки раз в секунду — не выполняй в нём тяжёлые операции без необходимости.

Управляем Transform из кода

using UnityEngine; public class Rotator : MonoBehaviour
{ public float speed = 60f; void Update() { // каждый кадр вращаем объект вокруг оси Y transform.Rotate(0f, speed * Time.deltaTime, 0f); }
}
  1. transform — ссылка на компонент Transform этого объекта.
  2. Time.deltaTime — время между кадрами: благодаря ему скорость не зависит от частоты кадров.
  3. public float speed — поле, которое видно в Inspector и можно менять прямо в редакторе.
Совет. Любое public-поле появляется в Inspector — это очень удобно: ты меняешь скорость вращения, не редактируя код.

Практика: перемещение объекта

using UnityEngine; public class Mover : MonoBehaviour
{ public float speed = 3f; void Update() { float h = Input.GetAxis("Horizontal"); // A/D или стрелки transform.Translate(h * speed * Time.deltaTime, 0f, 0f); }
}
  1. Создай скрипт Mover и повесь на сферу.
  2. Запусти игру (▶) — двигай сферу клавишами A/D.
  3. Проверь окно Game: объект должен перемещаться влево-вправо.

Исправляем ошибки (Console)

  • Красные ошибки — игра не запускается; жёлтые предупреждения — игра работает, но лучше поправить.
  • Двойной клик по ошибке в Console открывает строку кода с проблемой.
  • Частые причины: несовпадение имени класса и файла, пропущенная точка с запятой, опечатка в имени метода.
Важно. Не удаляй ошибку «закрытием окна» — она не исчезнет. Читай текст ошибки и исправляй код.
