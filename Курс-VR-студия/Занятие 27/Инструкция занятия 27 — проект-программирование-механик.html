1. Собери сцену-каркас

Создай сцену с XR Origin, полом и основными объектами из ТЗ.

✓ Должно получиться: Сцена собрана, объекты на местах.

2. Программируй первую механику

Реализуй движение/телепортацию и захват объекта (XR Interaction Toolkit).

✓ Должно получиться: Игрок может перемещаться и брать объекты.

3. Добавь реакцию объектов

По ГДД добавь реакцию: кнопка меняет цвет/состояние, дверь открывается.

✓ Должно получиться: Объекты реагируют на действия игрока.

4. Соедини механику с логикой

Реализуй счёт, таймер или условие победы из ГДД.

✓ Должно получиться: Есть игровая логика «условие → результат».

5. Тестируй в редакторе

Запусти в Editor, пройди механику, исправь ошибки. Повтори для каждой механики.

✓ Должно получиться: Основные механики работают без критичных багов.

Результат занятия

Что должно получиться: Работающие основные механики VR-проекта, описанные в ГДД, с проверкой в редакторе Unity.
