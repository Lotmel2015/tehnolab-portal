# Сквозная система регистрации и личного кабинета ТЛ

**Модуль:** `tl-portal-core.js` (лежит рядом с порталом: `ТЛ\ТЛ концепция\tl-portal-core.js`)
**Версия:** 0.1.0 (фундамент)

Это инструкция для подключения единого кабинета к страницам курсов. Курсы создаются — модуль уже готов к подключению: на каждой странице курса достаточно подключить JS, и ученик/педагог сможет входить в тот же кабинет, что и на портале.

---

## Как это работает (без сервера, офлайн)

Все данные хранятся в `localStorage` браузера под общими ключами. Поэтому «сквозная регистрация» работает, когда:
- портал и курс открываются **с одного домена/хостинга** (или локально с того же пути), и
- браузер один (один профиль на компьютере).

Общие ключи хранилища:

| Ключ | Назначение |
|---|---|
| `tl.users` | База пользователей: `{ email: {id, role, name, cls, school, labs, ...} }` |
| `tl.session` | Текущая сессия: `{ email, role }` |
| `tl.progress.<courseId>` | Прогресс занятий курса `{ lessonId: {done, at} }` |
| `tl.waitlist` | Список желающих записаться/узнать о запуске |

Роли:
- `learner` — обучающийся (видит свои курсы, прогресс, класс/школу);
- `teacher` — педагог/наставник (в кабинете отображается роль «Педагог»).

## Подключение к странице курса

### 1. Скопируйте рядом с курсом файл `tl-portal-core.js`

Он должен быть доступен по тому же пути, что и страницы курса (или по относительной ссылке).

### 2. Подключите в `<head>` страницы курса

```html
<script src="tl-portal-core.js"></script>
```

### 3. Добавьте кнопку входа

Модуль сам находит кнопки с классом `tl-auth-btn` и переключает их на «Войти» / «Мой кабинет».

```html
<button type="button" class="tl-auth-btn">Войти</button>
```

Если кнопка уже есть, просто добавьте класс `tl-auth-btn`.

### 4. Инициализируйте модуль в конце страницы (перед `</body>`)

```html
<script>
  TLCore.init({ /* опции */ });
</script>
```

### 5. (Опционально) Привязка курса и прогресс

Когда страница курса знает свой `courseId`, отметьте пройденное занятие, чтобы прогресс появился в кабинете:

```js
// отметить «занятие пройдено» (например, при нажатии «Завершить занятие»)
TLCore.setLessonDone('vr-studio', 'lesson-01', true);

// проверить, пройдено ли занятие
var done = TLCore.isLessonDone('vr-studio', 'lesson-01');

// показать панель кабинета по клику (если кнопки нет)
TLCore.openCabinet();
```

`courseId` — произвольная строка, одинаковая для всех занятий одного курса (например, `robototechnika`, `elektronika`, `vr-studio`, `blender`, `kompas-3d`, `bpla`, `proekt`).

## Использование на портале (уже подключено)

На портале `Портал Технологическая лаборатория.html` уже есть:
- кнопка «Войти» / «Мой кабинет» в шапке;
- модальное окно «Вход / Регистрация» с полями (ФИО, класс, школа, телефон, роль, выбор лабораторий);
- панель личного кабинета;
- раздел «Материалы и курсы» (каркас под будущие курсы).

## API (кратко)

| Метод | Описание |
|---|---|
| `TLCore.currentUser()` | Текущий пользователь или `null` |
| `TLCore.isTeacher()` | `true`, если текущий пользователь — педагог |
| `TLCore.openAuth('login'|'reg')` | Открыть окно входа/регистрации |
| `TLCore.openCabinet()` | Открыть панель кабинета |
| `TLCore.setLessonDone(courseId, lessonId, true/false)` | Отметить занятие |
| `TLCore.getProgress(courseId)` | Прогресс курса |
| `TLCore.waitlist(courseId, label)` | Добавить в лист ожидания курса |
| `TLCore.refreshUI()` | Обновить кнопки после смены сессии |

## Важно (для перехода на сервер)

Используемая «хэш-функция» пароля — демонстрационная (небезопасная). При размещении портала на реальном сервере с бэкендом:
- заменить локальное хранилище на серверную БД и сессии (cookies/JWT);
- заменить хэш пароля на надёжный (bcrypt/argon2);
- прогресс и профиль хранить на сервере, чтобы он был доступен с любого устройства.

На этапе прототипа/демо модуль полностью автономен.
