1Пошаговые действия

Выполняй 5 шагов по порядку.

1Запусти Visual Studio. Если проекта ещё нет — Файл → Создать → Проект.

Открой среду

✔ { Откроется окно выбора шаблона проекта. }
2Выбери «Консольное приложение (C#)» и нажми Далее. В названии напиши Booka.

Создай консольный проект

✔ { Появится окно кода с текстом Hello, World!. }
3Замени Hello World на строки с переменными из теории.

Набери первый код

✔ { После набора строк под ними не будет ошибок. }
4Нажми кнопку ▶ наверху или клавишу F5.

Запусти программу

✔ { Откроется чёрное окно с результатом, например 100 и 3,5. }
5Добавь :F2 и :N0 в вывод числа и запусти снова.

Проверь форматы

✔ { Число появится с запятой и разделителем тысяч. }
Если что-то не работает. Если запустил и сразу всё закрылось — в конец Main добавь Console.ReadKey();, чтобы окно ждало нажатия клавиши.
Правило. Код набирай руками, а не копируй целиком. Ошибки и их исправление — и есть обучение.

2Обратно к модулю

Когда выполнишь практику и домашнее задание — вернись в модуль, отметь галочку «Я выполнил» и сохрани результат в рефлексии.
