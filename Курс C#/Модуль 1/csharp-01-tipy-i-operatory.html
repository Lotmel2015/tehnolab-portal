1

Зачем нужен тип данных

Компьютер хранит каждую величину в памяти и должен заранее знать, какого она вида: число это или слово. Этот вид и называется типом данных. Выбор правильного типа — первая команда программиста.

Скопируй этот код
int age;          // целое число (для возраста, очков, жизни)
float speed;       // дробное число (для скорости, координат)
bool isMood;       // правда или ложь (для флагов «жив», «включён»)
string name;       // текст (для имени, названия)
Что ты увидишь на экране
При объявлении переменных на экране ничего не появится — это просто «заметка» для компьютера.
Запомни. Тип = какой вид данных. int (целое), float (дробное), bool (да/нет), string (текст).
2

Целые и дробные числа

Для целых чисел (3, -7, 0) используется int. Для дробных (3.5, -0.25) — float. В играх у человека здоровье int (80), а скорость передвижения float (5.5). К дробному числу в C# добавляют букву f — это знак, что число дробное.

Скопируй этот код
int score = 100;        // целое очко
float speed = 3.5f;      // дробная скорость. Буква f в конце ВАЖНА!
Console.WriteLine(score);
Console.WriteLine(speed);
Что ты увидишь на экране
На экране появятся две строки: 100 3,5
Запомни. Целое число — int, дробное — float. У дробного в коде в конце ставим f.
3

Слова и правда/ложь

Текст хранится в string, в кавычках "...". Правда или ложь — в bool, словами true (правда) и false (ложь). bool удобен для переключателей: «жив ли персонаж», «открыта ли дверь».

Скопируй этот код
string player = "Аня";
bool isAlive = true;
Console.WriteLine("Игрок: " + player);
Console.WriteLine("Жив: " + isAlive);
Что ты увидишь на экране
На экране: Игрок: Аня Жив: True
Запомни. Текст пишем в кавычках — string. Правда/ложь — true/false — bool.
4

Выводим числа красиво

С помощью $ можно вставить переменную прямо в текст, а с помощью :F2 — написать число с двумя знаками после запятой (например, для цен и измерений).

Скопируй этот код
double price = 1234.5;
Console.WriteLine($"Цена: {price:N0} руб.");
Console.WriteLine($"Точная: {price:F2}");
Что ты увидишь на экране
На экране: Цена: 1 235 руб. Точная: 1234,50
Запомни. $ и {переменная} — вставить переменную в текст. :F2 — два знака после запятой, :N0 — тысячи.
5

Приведение типов

Чтобы превратить дробное число в целое, не хватает простого присваивания — нужно явное приведение: (int). Простое (int) отбрасывает дробную часть, Convert.ToInt32 округляет.

Скопируй этот код
double d = 59.7;
int a = (int)d;            // отбросит дробь → 59
int b = Convert.ToInt32(d); // округлит → 60
Console.WriteLine(a);
Console.WriteLine(b);
Что ты увидишь на экране
На экране: 59 60
Запомни. (int) — отбрасывает дробную часть. Convert.ToInt32(...) — округляет.

01·ВДомашнее задание

📋 Напиши программу-«смету»: стоимость 3 предметов с налогом 13%.

  1. Заведи три переменные int с ценами товаров.
  2. Посчитай сумму и сохрани её в переменную sum.
  3. Посчитай налог: sum * 0.13f и сохрани в tax.
  4. Выведи итог строкой: «Итого с налогом: ... руб.» и налог с двумя знаками (:F2).
  5. Запусти (F5) — на экране должны быть сумма, налог и итог с налогом.
Что должно получиться: Ты увидишь три числа: сумму товаров, налог и общую стоимость с налогом (с копейками).
