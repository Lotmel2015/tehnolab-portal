Зачем хранить много данных

В игре десятки очков, врагов, уровней. Хранить их по отдельным переменным неудобно — поэтому есть массивы и списки.

Массив или список

Массив — фиксированный набор (нельзя добавить). Список — можно добавлять и удалять. Начнём с массива.

1

Массив — набор значений

Массив держит несколько значений одного типа. Элементы нумеруются с 0. Число элементов — arr.Length.

Скопируй этот код
int[] scores = { 3, 5, 2 };
Console.WriteLine(scores[0]); // первый элемент
Console.WriteLine(scores.Length); // сколько элементов
Что ты увидишь на экране
На экране: 3 3
Запомни. Массив = набор значений. Первый элемент — индекс 0. Количество — Length.
2

Список List — можно добавлять

List — список, который растёт. Добавляем через Add, удаляем через Remove. В начале нужен с помощью using System.Collections.Generic.

Скопируй этот код
List enemies = new List();
enemies.Add("слайм");
enemies.Add("скелет");
enemies.Remove("слайм");
Console.WriteLine(enemies.Count);
Что ты увидишь на экране
На экране: 1
Запомни. List — динамический список: Add добавить, Remove удалить, Count количество.
3

Методы — именованные блоки

Метод — это именованный кусок кода, который можно вызвать несколько раз. static int Max(int[] a) — метод, принимающий массив и возвращающий int.

Скопируй этот код
static int Max(int[] a) {
    int m = a[0];
    for (int i = 1; i < a.Length; i++)
        if (a[i] > m) m = a[i];
    return m;
}
int[] s = { 3, 9, 4 };
Console.WriteLine(Max(s));
Что ты увидишь на экране
На экране: 9
Запомни. Метод = имя + параметры + тело + return. Вызываешь — получаешь результат.
4

Случайные числа Random

Random генерирует случайные числа. rnd.Next(1, 11) — число от 1 до 10 (второе число не входит). Один Random на программу.

Скопируй этот код
Random rnd = new Random();
int n = rnd.Next(1, 11);
Console.WriteLine(n);
Что ты увидишь на экране
На экране — случайное число от 1 до 10 (каждый запуск новое).
Запомни. Random — random.Next(мин, макс) даёт случайное от мин до макс−1.
