03·AТеория по шагам

Внимательно прочитай каждый шаг по очереди. Не спеши — после каждого шага проверяй себя на «что увидишь».

Что такое цикл

Цикл — это повторение блока кода. Вместо того чтобы писать Console.WriteLine десять раз, пишем один цикл, который повторит его 10 раз.

Два главных цикла

for — когда заранее известно, сколько повторений. while — когда повторяем, пока условие истинно.

1

Цикл for — по счёту

for (start; условие; шаг) повторяет код известное число раз. Три части: начинаем с i=1, пока i<=5, каждый проход i++ (увеличиваем на 1).

Скопируй этот код
for (int i = 1; i <= 5; i++)
    Console.WriteLine("Игрок " + i);
Что ты увидишь на экране
На экране: Игрок 1 Игрок 2 Игрок 3 Игрок 4 Игрок 5
Запомни. for (начало; условие; шаг) — повтор по счёту. i++ = прибавить 1.
2

Цикл while — пока…

while (условие) повторяет, пока условие истинно. Важно менять переменную внутри цикла, иначе он не остановится (зациклится).

Скопируй этот код
int coins = 3;
while (coins > 0) {
    Console.WriteLine("Монет: " + coins);
    coins--;
}
Что ты увидишь на экране
На экране: Монет: 3 Монет: 2 Монет: 1
Запомни. while (условие) — повтор, пока правда. Не забудь менять переменную, иначе зациклится.
3

foreach — по списку

foreach перебирает все элементы коллекции или массива, не заботясь об индексах. Удобно перебрать список врагов или предметов.

Скопируй этот код
string[] fruits = { "яблоко", "груша", "банан" };
foreach (string f in fruits)
    Console.WriteLine(f);
Что ты увидишь на экране
На экране: яблоко груша банан
Запомни. foreach (элемент in коллекция) — перебирает все элементы.
4

break и continue

break — мгновенно выйти из цикла. continue — пропустить текущий проход и продолжить со следующего.

Скопируй этот код
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;        // стоп на 5
    Console.WriteLine(i);
}
Что ты увидишь на экране
На экране: 1 2 3 4
Запомни. break — выйти из цикла. continue — пропустить этот проход.
5

Вложенные циклы

Цикл внутри цикла. Внешний — по строкам, внутренний — по столбцам. Классика — таблица умножения.

Скопируй этот код
for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= 3; col++)
        Console.Write(row * col + " ");
    Console.WriteLine();  // новая строка
}
Что ты увидишь на экране
На экране: 1 2 3 2 4 6 3 6 9
Запомни. Вложенные циклы: внешний привышает строки, внутренний — столбцы.

03·ВДомашнее задание

📋 Нарисуй «ёлку» из звёздочек высотой 5 уровней.

  1. Внешний цикл — по уровням (1…5).
  2. Во внутреннем цикле напечатай столько звёздочек, сколько номер уровня (первый уровень — 1, второй — 2…).
  3. Перед звёздочками добавь пробелы, чтобы ёлка была по центру.
  4. После каждого ряда — переходи на новую строку.
  5. Запусти — получится пирамида из звёздочек.
Что должно получиться: В консоли — треугольная «ёлка» из звёздочек высотой 5 рядов.
