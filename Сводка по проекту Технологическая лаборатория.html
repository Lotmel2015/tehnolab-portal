Проект. Статический сайт объединения «Технологическая лаборатория» (КГАОУ «Школа космонавтики», Железногорск) + электронные курсы для школьников 8–11 классов. Всё работает на localStorage без сервера, файлы открываются с диска (file://) и с GitHub Pages. 2. Как устроена логика (архитектура)

  • Вход через портал. Профили хранятся в общем localStorage портала (tl.users, сессия tl.session). Переход на курс идёт с параметром ?tl_email=…; tl-bridge.js создаёт профиль курса по email (двухпутевая синхронизация: общий localStorage на http / URL-параметр на file://).
  • Профили курсов. Два вида id-моделей: uid (строковый, для Проектного навигатора, VR и др.) и id (числовой, для 4 упрощённых курсов). Сессия для id-моделей пишется строкой id, а не JSON — критично!
  • Прогресс. Два формата: lesson_l (массив булевых или ключ {uid}_l_{n}='1') и week_obj (объект {w1:true,…}). У ПН — pdn-course-progress-{uid} как массив из 36 булевых.
  • Блокировка занятий. Последовательная: занятие доступно если num===1 || isDone(uid, num-1); учитель видит все. Строгая блокировка — через рефлексию (галочку): следующее открывается только после заполнения рефлексии предыдущего.
  • Мотивационная шкала. Металлы (Железо…Иридий), баллы: прогресс (до 40) + качество (до 60) = итог 0–100; лидеры среди учеников курса.
  • Квизы. Модуль tl-quiz.js + TQuiz.start: 3 вопроса «что / зачем / что при ошибке» в каждом уроке, счёт и сохранение.

3. Канон сборки курса (жёсткие правила)

Правило 1. Один префикс ключей localStorage на курс (например rt_). Правило 2. Один inline <script> на страницу. Правило 3. В минифицированном JS только /* */-комментарии, никогда //. Правило 4. Строгая последовательная блокировка следующего шага через рефлексию.

Сборка: конфиг JSON → генератор → хаб («Список занятий») → уроки (теория/практика/рефлексия/галочка/квиз) → шкала → проверки.

Подключение внешних скриптов — перед последним </html> (теги </body>/</html> встречаются в JS-строках).

  • Болевые точки сотрудников — закрыты все 5 пунктов (окт. 2026):
    • Кабинет педагога: сводка по группам и прогрессу учеников (getStudentsForTeacher, форматы lesson_l/week_obj), блок «Мои ученики» в ЛК; педагог видит своих, админ/завуч — всех.
    • Единый реестр педагогов: tl.teachers (код учителя + список), управление в ЛК администратора; курсы читают код/список через TLCore (fallback на прежние значения).
    • Журнал ТО для лаборанта: tl-to в панели «Контроль» — комплекты со статусами (в норме/скоро ТО/нужно ТО), расходники с мин. остатком, привязка оборудования к занятиям.
    • Дашборд объединения: для завуч/админ — охват учеников, исполнение задач контроля, команда, бюджет, МТБ, доля практики (67%).
    • Полный экспорт/импорт JSON: «Экспорт всех»/«Импорт всех» (admin) — все ключи портала + ядра (tl.users, tl.teachers, tl.progress.* и др.), перенос между устройствами.
  • Модернизация личного кабинета (окт. 2026) — полноэкранный ЛК с вкладками:

6. Уроки и подводные камни (что ломалось)

  • «Занятия не отображаются» (ПН, 13.10.2026): функция отрисовки render() была перекрыта одноимённой функцией мотивационной шкалы — #grid пустой. Лечение: канонический render() (цикл по lessons, блокировка) + шкалу назвать scaleMain и вызывать через window.__scaleRender в конце render(). Из файла также удалены 7 дублей userbar и 3 дубля studentsPanel.
  • Массовый дефект адаптивности: CSS-блок «АДАПТИВНОСТЬ…» был вставлен внутрь <script> в ~138 файлах (ломало JS). Починено; при пакетных правках: маркер не должен встречаться внутри <script>, проверять node --check.
  • Приложение-10 ПН: потерянная } в JS — пересобран.
  • Ссылки без ?uid в ПН — урок не знал профиль; починено.
  • «Оголённые атрибуты»: после замены формы на плашку терялся открывающий <div class="userbar" — восстановлен, парность <div> сходится.

7. Как действовать дальше (рабочие правила)

  1. Все имена файлов — на русском, без - и _ между словами (те же имена тем, что уже используются).
  2. Все внешние ссылки — открывающиеся в РФ без VPN (не YouTube/ArtStation/Behance/Canva/Tinkercad и т.п.); проверять каждую.
  3. Курсы строить строго по канону VR; VR — эталон. При правках ядра tl-portal-core.js — не терять API/renderCabinet/renderAuthWidget, сверять md5 8 копий.
  4. После пакетных правок: node --check/глобальный global-syntax-check.cjs (сейчас 395 файлов, 0 ошибок).
  5. Функция отрисовки занятий в хабе — обязана называться render(); шкала — window.__scaleRender; не перекрывать.
  6. Перед изменением файла — прочитать; изменения — только по явной просьбе (вопросы «посмотри/изучи» — только чтение).
  7. Деструктивные действия (reset, удаление, перезапись) — только после подтверждения пользователя.
  8. В ответах — кратко, на русском; служебные скрипты — в C:\Users\Lotmel\AppData\Local\Temp\gigatool.
